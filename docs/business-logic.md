# 业务逻辑规格（计算引入后的单元间规则）

> 回答"一大堆计算怎么在业务上串起来"：参数从哪来、谁跟谁耦合、哪里必须
> 守恒、初始参数不可行时怎么引导用户调到可行。上位文件：ADR-007（工况）、
> ADR-008（方法路线）、ADR-009（默认值）；单元级物理不变性见各单元包
> `tests/properties.py` 规格。实现期本文各节由对应模块的规格头引用执行。

## 1. 参数初始化链（初始参数从哪来）

```
manifest 默认值（带条文出处，units_lib 各包声明）
   → assumptions 注入（registry/assumptions 唯一真源：跨单元工程假设，
     含出处/适用条件/调节影响元数据；项目文件 assumption_overrides 覆盖）
   → 用户参数覆盖（design 态，参与 content-hash）
   → 工况映射（manifest 声明式规则：n_active 等，ADR-007）
   → compute 消费（代码内零数值字面量，见 §9）
```

**初始参数不保证可行是设计预期**（工程组合空间巨大）：第一次 F5 允许
约束失败，失败不是错误而是方案空间探索的入口（§4）。

## 2. 耦合参数单一归属表（防双源）

| 耦合量 | 唯一归属 | 其他单元如何获得 |
|--------|----------|------------------|
| 外回流比 R、MLSS、污泥负荷 Ns、内回流比 Ri | AAO/CASS manifest（可枚举自由参数） | 二沉池经 UnitContext 接收（只读） |
| 二沉池固体负荷 | 二沉池派生量（由 R、MLSS 计算） | 不反向影响 AAO，仅出校核警告 |
| 高密池污泥回流比 3%~5% | 高密池 manifest（单元内部变量） | 泥量入污泥衡算 |
| 化学除磷药剂摩尔比 | data/coefficients（§7.10.5） | 化学泥量公式引用键取值 |
| 汇流 Kz | 取 max（graph/propagate 语义） | 各支流只提供自身量 |
| 泥量含水率链 | 各单元 manifest 改写并产出新 SludgeFlow | 禁原地修改（无状态传播） |
| 工况键 condition_key | 图引擎分配 | 全链路只读 |

规则：**耦合量的"值"只在一处拥有**；他处一律经结果契约读取。
违反 = 双轨病灶复发（旧系统 Q_design 双轨教训）。

## 3. 守恒断言点（性质测试挂钩，违反即失败）

| 断言点 | 守恒律 | 测试落点 |
|--------|--------|----------|
| 汇流节点 | Σ流出流量 = Σ流入；浓度按当前工况流量加权 | graph/propagate 性质测试 |
| 污泥合并 | 湿量加和守恒；DS 加和守恒 | sludge/hebing properties |
| 浓缩/消化/脱水/干化 | DS 守恒（进 = 出固 + 流失/上清）；含水率单调下降 | 各包 properties |
| 化学除磷 | 化学泥量计入污泥线（GB 50014-2021 §8.1.6） | gaomidu + 污泥线联测 |
| 巴歇尔槽/管段 | 流量守恒（无源汇假设显式声明） | 通用性质 |
| 高程链 | 水面衔接连续（跌水/提升显式事件化，不静默消失水头） | elevation/profile |

## 4. 可行解迭代流程（工业级调节，核心产品语义）

初始参数不可行时的标准闭环（**绝不静默改参数**）：

```
F5 计算 → 约束过滤（solution/constraints，pass_matrix）
  ├─ 有可行解 → 排序输出（裕度/成本）
  └─ 无可行解 → 诊断（solution/diagnose：最小冲突集）
        → 输出建议清单（每条含：参数键 / 调节方向 / 建议幅度 /
          依据条文或知识库条目 / 预期影响哪个冲突约束）
        → 用户调整（手动改，或"建议应用"= 显式 design 变更，进计算迹）
        → 重算（增量），循环直到可行或用户放弃
```

- **建议来源三条**（按优先级）：①约束知识库规则（data/constraint_kb，
  每条约束可挂"失败时建议"，带出处）；②枚举统计（该参数在可行域边缘
  的分布 → 方向与幅度建议）；③专家经验表（coefficients，如
  BOD5/TN<4 时建议"超越初沉或外加碳源"）。
- 建议是**建议**：一键应用必须落 design 态变更 + 新 content-hash +
  结果 stale 标记（§17.1 事件规则），不允许后台自调。
- UI 对应落点：`features/solutions/DiagnosisPanel`（持久面板）+
  `features/params`（建议高亮参数键）。

## 5. 约束联动链（上游承诺 → 下游要求）

| 上游产出承诺 | 下游进水要求 | 依据 | 联动语义 |
|--------------|--------------|------|----------|
| 高密池出水 SS | V 型滤池进水 SS < 20 mg/L | GB 50014-2021 §7.11.7 | 承诺字段进 result_schema，constraint_kb 自动校核 |
| V 型滤池出水 SS ≤ 10 | 紫外有效剂量的进水前提 | §7.11.8/§7.13 | 剂量计算绑定进水浊度档，超标出警告 |
| AAO 进水 BOD5/TN ≥ 4 | 反硝化碳源充足性 | 手册经验（B16 层级二） | 初沉超越开关（B4）触发依据 |
| 二沉池出水 SS | 高密池进水衔接 | 工艺链 | 汇流节点自动衔接 |
| 污泥线含水率链 | 脱水/干化进泥档位 | 各单元 manifest | 档位不匹配 = 显式配置错误 |

## 6. 回路与边标记清单（graph/loop 迭代对象）

| 环 | 边语义 | 迭代归属 |
|----|--------|----------|
| 污泥外回流 R：二沉池 → 生物池 | `recycle: true` | SCC 回路组，固定点迭代 |
| 内回流 Ri：好氧末端 → 缺氧区 | `recycle: true`（AAO 包内部端口） | 同上 |
| 高密池污泥回流 | 单元内部变量（不出包边界） | manifest 声明，不走图迭代 |
| 浓缩上清液/脱水滤液 → 厂首端 | `recycle: true`，**默认关闭** | 打开后进 SCC；泥量与水量双向守恒 |

> 滤液/上清液回流是真实厂常态，但两个 golden 案例是否包含需领域专家
> 确认（见 §10 待确认项 Q1）——确认前默认关、UI 显式开关。

## 7. 离散枚举对象清单（solution/grid 的自由参数域）

管径（管网）、水泵台数、巴歇尔槽喉宽档（B7 七档）、池数/分格数（≥2、
V 滤 ≥4）、CASS 周期档、消化温度档、干化出泥档（B14）。枚举语义按
ADR-005：单单元枚举 + 全厂传播；离散档位即 manifest 声明的 grid。

## 8. 警告分级与工业级提示规格

| 级别 | 语义 | UI |
|------|------|-----|
| error | 约束硬失败/配置非法 | 计算失败 + 诊断面板 |
| warn | 越出建议带但未违反强条（如泥龄出 11~23d 带） | 语义色橙 + 依据条文 |
| info | 设计假设生效提示/裕度充裕 | 灰阶 |

每条警告必带：来源（条文/知识库键）+ 调节方向提示（指向参数键）+
影响面（哪个工况/哪个下游单元）。禁止无出处的裸警告文本。

## 9. 严禁魔法数字的执行（机器强制）

- 门禁 `scripts/check_magic_numbers.py`：内核 .py 代码中数值字面量仅
  允许 0/1/2/10，且只许出现在 `registry/**`、`contracts/quantity.py` 与
  `units_lib/**/manifest.py`（真源区；units_lib 白名单按"前缀+文件名"
  双条件精确命中 manifest.py——manifest 默认值 = 带出处的声明式真源，
  同前缀下 compute.py 等其余 units_lib 文件继续严管）；其余一律引用
  注册表/假设清单/系数库。
- 假设条目五字段：键 / 默认值 / 出处 / 适用条件 / **调节影响**（供 §4
  建议引擎消费）——没有调节影响元数据的默认值 = 不合格假设条目。
- AGENTS.md §3 同步此规则；评审口径：代码里出现 24、0.5632、3000
  这类数 = 评审拒绝（24h/day 也要经 quantity 单位常量）。

## 10. 工程合理性校核记录（2026-08-22，对 ADR-008/009 路线组的交叉审计）

| # | 检查项 | 结论 |
|---|--------|------|
| 1 | AAO 负荷法（Ns 0.10~0.15）× MLSS 2.5~4.5 与二沉固体负荷 ≤150（R 50%~100%）参数带自洽 | ✅ 常规组合（X=3.5、R=100%）在带内；R=100%+X=4.5 时固体负荷成为控制项——正是"max 面积"双控设计所预期 |
| 2 | 污泥产率 y（AAO 0.4~0.6）与 Y/Kd 机理法（Y 0.4~0.8、Kd 0.04~0.075）量级一致性 | ✅ 典型工况两法偏差 10%~30%，互校阈值 20% 合理；偏差主因 SS/BOD 比——已入 §4 建议文案 |
| 3 | 高密池液面负荷 10~20（GB/T 50335）与矿井水侧 15~30（文献）带重叠 | ✅ 矿井水线独立包参数域更宽（§14.3 跨线隔离正为此）；两包不共享参数键 |
| 4 | 高密出水 SS 承诺与 V 滤进水 <20 联动 | ✅ §5 链 1 已建；高密出水 SS 需作为 result_schema 承诺字段（M1 冻结字段 ID） |
| 5 | V 滤周期 12~24h 与进水 SS 承诺一致性 | ✅ 周期受进泥负荷影响，作为派生输出而非固定输入 |
| 6 | 消化产气 0.75~1.0 Nm³/kgVS去除 与气柜 6~10h 锚点相容 | ✅ 气柜按产气量派生，无循环依赖 |
| 7 | 干化热耗 3000 缺省 < 3300 红线 | ✅ 且 §8.7.3 说明"不计设备散热"，计算书须注明口径 |
| 8 | CASS 4h 周期 × 滗水容积 ≤ 池深 1/3（滗水 1.0~2.0m） | ✅ 与池数≥2 联动校核已在包不变性（时段和=周期、滗水容积≤池容） |
| 9 | 回路识别完整性 | ⚠️ R/Ri/高密回流/滤液回流四处已列 §6；滤液回流默认关待 Q1 |
| 10 | 工况映射与"初沉池旱季设计/雨季校核"条文 | ⚠️ v1 分流制下 design 档=最高日最高时已覆盖；合流制截流校核（雨季）为后续扩展轴，不在 v1 工况轴内（ADR-007 开放封闭） |

# ADR-003：回路迭代策略（固定点 + 阻尼 + 发散诊断）

- 状态：**已接受**（计划 §3-3/§8；M1 落地，污泥线 M3 实战）
- 背景：旧系统 DAG 环路直接异常，污泥回流只能绕行；回流/内回流必须成为
  一等公民。
- 决策：
  1. recycle 边标记 → SCC 划分 → 回路组交固定点迭代（graph/loop.py）；
  2. 迭代式 x_{n+1} = x_n + ω(F(x_n) − x_n)，阻尼 ω 来自 assumptions；
  3. 收敛判据：全部回路变量相对残差 < tolerance（assumptions）；
  4. 超最大迭代 = 抛 LoopDivergence（含回路节点/迭代历史/震荡信息），
     UI 给出拆环建议；**禁止静默返回最后一次迭代值**；
  5. 非 recycle 边构成的环（用户误连）仍是异常（InvalidConnection）。
- 后果：个别高回流比拓扑可能不收敛需人工拆环（残余风险 §16 A2 接受）；
  远期 Broyden/Anderson 加速作为可替换策略注入，接口不变。
- 细化归属：M1 loop.py + 三单元线性图；M3 污泥线全链。

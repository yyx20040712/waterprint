# ADR-019：AI 永不直算（agent 面第一铁律）

- 状态：**已接受**（AI1 战役路线级设计终裁 2026-09-13——三段通道
  [Kimi 拟定 v1→deepseek 对抗审核回炉→Kimi v2→主控终裁]定案；
  用户五项裁决 R1~R5 授权链）。
- 背景：
  - AI1 战役为 WaterPrint 增设 agent 面：外部 AI 智能体（ZCode 等
    MCP 客户端宿主）经自然语言指令驱动设计计算与成果输出。
  - 内核既有资产：确定性计算（同输入字节级复算）、逐公式 trace
    （公式 ID/表达式/规范条文）、repro 三元组、审计报告——可信度
    是产品第一卖点。
  - 若允许 AI 直接产出数值（心算/编造），上述信任链全部作废且
    无法审查——AI 幻觉数字进入工程计算是不可审计的风险。
- 决策：

| # | 决策 | 理由 |
|---|------|------|
| D1 | **AI 在 agent 面只允许两种产出：流程组织指令与参数决策建议；一切数值必须出自 core 确定性内核**（AI 调 wp_run_calc 等工具获得内核计算结果，不得自行生成任何进入项目/成果的数字） | 保住"每个数字可溯源到公式与条文"的信任链；AI 编排+内核算数的分工让 AI 的贡献可核查 |
| D2 | **设计说明书管线采用分段混合制（N3）**：计算章（2/4/6）纯程序生成，AI 零接触；叙述章（3/5）程序先注入全部数值结论（占位符回填），AI 仅承接已注入结论撰写论证文字，正文禁新增数字（validate_narrative 正则后检，检出即拒重写） | "AI 永不算数"在文字面的自然延伸——支撑数字由程序给，不由 AI 写；后检属缓解非根除（中文数字变体），记档 K4 |
| D3 | **wp_export_report 落盘前置断言**：verify_report 四面（公式 ID 可查/锚定值与 serialize 逐项相等/未锚定值落值域全集/叙述区零数字违例）全绿才允许写出 | 数值锚定是硬门禁不是最佳努力 |

- 后果：
  - 正面：agent 面的全部产出（项目参数/计算结果/说明书）保持可审计、
    可复算、可逐值核查——"AI 驱动"不稀释反而强化可信度卖点。
  - 代价：说明书叙述章生成需"程序注入→AI 撰写→后检→重写"循环；
    水质类传播结果不在 trace 输出面（golden 实测 0/72），水质表只
    程序填表不挂锚（诚实不伪锚）——内核为传播节点入迹属内核批
    挂账。
  - 关联：ADR-020（agent 面分层边界）、ADR-021（同步模型与沙箱）。

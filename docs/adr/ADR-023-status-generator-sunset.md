# ADR-023：status.md 计数生成源 + 治理件 sunset 登记表（复杂度治理批 1）

- 状态：**Accepted**（用户五裁决 2026-09-18「README 砍成三行+指针，需要留的
  数字单独生成到 docs/status.md」+「sunset 机制极简形态=一张登记表+触发条件，
  不新增门禁脚本」；批 1 落地 commits 34128a9/8b69253，门一异源审 R1 复签
  PASS，CI status 零漂移步骤首跑绿=run 35348257364 server job）。
- 背景：
  - 深度审计裁决（2026-09-12）已定性「复杂度爆炸点在治理/过程面」；本项目
    实录：锁面键数 274/270/296 三说、门禁数 12/14/15 三说、快照哈希四/三
    两说、index.md「ADR-001~009」对 22 件、user-manual「19 端点」对 35 操作
    ——**手写计数是漂移震中**，且 README 状态段 178 行批次编年史自违
    「文档不手写数字」原则数十处。
  - 治理面只增不减（门禁 11→15、GR 42 条、test-lock 270→296），无退役
    机制——治理件自身熵增无制动力。
- 决策：

| # | 决策 | 理由 |
|---|------|------|
| D1 | **计数单一生成源**：`scripts/gen_status.py`（纯标准库）→ `docs/status.md`；指标全**文件派生**（门禁数=run_gates GATES 元组/锁面键数=manifest JSON/OpenAPI/ADR/UF 表行/数据包版本/快照锚/单元包数/webapp 测试文件数），零环境依赖 | 文件派生=任意环境可再生成（CI 字节比对可机判）；用例数/覆盖率等环境派生值**不生成**、仍以 CI 输出为准（ADR-016 行数注记同族边界） |
| D2 | **确定性输出+零漂移机检**：无时间戳/行序静态固定/`--check` 重生成字节比对；CI server job 挂「status.md 零漂移」步骤（不进 run_gates GATES——生成器纪律非门禁，防门禁数膨胀） | 生成物漂移=fail-loud；同款先例=OpenAPI 契约零漂移步骤 |
| D3 | **手写计数退役纪律**：README/文档群不再手写计数，一律指针「以 docs/status.md 为准」（批 1 同步勘误 testing/index/user-manual 三处+README 状态段砍四行、编年史迁仓外归档区） | 漂移类根除=消灭手写面而非追着手改；README 旗舰段「32 单元」自违宣言实录（门一 B1）证明仅靠纪律不够，须生成源兜底（count_units 指标因此入集） |
| D4 | **sunset 登记表极简形态**：`docs/governance-sunset.md` 单表——三类触发条件模板（S1 对象消失/S2 长期零触发 ≥10 批/S3 被覆盖）；登记≠立即退役；软退役=原文保留不删改；表 >50 行触发人工盘点；**零新增门禁脚本** | 用户裁决形态；治理件退役需要登记面但不再造机检（治理面熵增的解药不是更多治理）；历史红线纪律同技能 08 §3 |
| D5 | **UF 状态分类口径**：status.md 的 UF 计数按状态列前缀分类，不规则表述入「其他表述」桶外显 | 诚实分类优于静默归并；9 条不规则表述因此暴露=待 UF 维护批规范 |

- 后果：
  - 正面：手写计数漂移类根除（指标变动=同批重生成入库，CI 比对拦截漏更）；
    治理件自此有退役通道（首批 9 条登记、6 条已退役）；README 263→93 行。
  - 代价：新增生成器+登记表两件维护面（改指标集/新增退役均须同批同步
    status.md/登记表）；「其他表述」桶待 UF 维护批消化；unit_prices 版本
    字段实名 `price_data_version` 的通配识别=生成器对包实名变体的既有约定。
  - 关联：碳核算前置探针结论（电耗空白/药耗部分/运行成本缺位）与五方案
    设计随批落 `.workflow/plans/`（会话区，不入库——产出面纪律）。

# ADR-015：锁面 manifest CI 草稿重生成（机器出草稿，人审工序不变）

- 状态：**Accepted**（授权链=深度审计建议 B1「锁面 manifest 在 CI 增
  『与工作树不一致即提示』的自动重生成草稿（人类仍审，但机器出草稿）」
  →总控裁决《审计裁决与治理优化规划_GLM5.3.md》B-4 纳入 P1 路线图
  →GOV4 批 2026-09-12）。
- 背景：
  - test-lock.manifest.json 是全仓最热治理文件（148 次重锁实录）——
    测试变更后的重锁是 AGENTS §7 的人类显式事件（[HUMAN-LOCK] 信任根
    守卫双面拦截），此边界不动。
  - 漂移**检测**已完备（check_readonly 本地+test_lock CI）；人类成本
    在**修复动作的机器半边**：拼对覆盖全部既有条目的全根清单（GOV3
    键集反推法先例）+定位三类差异（新增/删除/哈希变）——拼错根清单
    曾触发 COST2 事故（裸跑挤掉 38 条目，键集守卫由此设立）。
- 决策：

| # | 决策 | 理由 |
|---|------|------|
| D1 | **草稿器=只读投影**：`scripts/draft_lock_manifest.py` 以 check_readonly 同一扫描宇宙实测工作树，与 manifest 比对输出三类差异+**可复制的全根清单重锁命令**（35 根：两默认根+33 包级 tests）；绝不写出 manifest | 机器半边代劳（拼清单+算差异），AGENTS §7 人类半边不变；扫描/哈希口径单源=import check_readonly（零信任根触碰，CRLF 归一/忽略集恒同） |
| D2 | **CI 接线=if: failure() 附着 gates job**：门禁绿=step 跳过（零噪声）；红=草稿 step 输出差异+命令（自身 exit 1 叠一面红，精确定位锁面） | 漂移检测不重复造（check_readonly 已拦）；草稿=红面补救指引——只在需要时出现 |
| D3 | **AI 可跑草稿器**：只读无写出，不属 AGENTS §7 禁项（禁项=跑 lock_tests.py/改 manifest） | AI 本地预检漂移=自证清白面（变更后自查锁面是否需呈报重锁） |
| D4 | **删除条目显式警示**：草稿含删除时提示 --prune 语义（键集只增不减守卫，COST2 设防） | 删除=高危方向（测试消失），草稿不消歧、只把守卫语义前置呈现 |

- 后果：
  - 正面：锁面从「人类拼根清单+算差异+跑重锁」降为「审草稿 diff+复制
    命令+跑重锁」——机器半边归机器（审计 B1 验收：手工登记面 ≥6→≤3
    的锁面贡献项）；AI 侧获得合规的自查工具。
  - 代价：draft_lock_manifest.py 新件登记（file-contracts §4）；ci.yml
    gates job 增一 step（绿面零成本）。
  - 首跑实录：一致面 exit 0（271 键）；漂移面（内存级 monkeypatch 模拟
    ——不触碰锁定树）三类清单+35 根命令+--prune 警示全呈，exit 1。

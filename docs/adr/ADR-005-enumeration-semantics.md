# ADR-005：方案枚举语义（单单元枚举 + 全厂传播）

- 状态：**已接受**（计划 §12.4；M2 落地）
- 背景：全厂联合枚举组合爆炸（10^10 量级，§11 R11）——不定义语义
  则功能不可用或误解需求。
- 决策：
  1. 枚举对象永远是**单个工艺单元**：上游结果（水量/水质）为固定上下文，
     自由参数网格 ≤4^k（grid 护栏强制）；
  2. 流程：离散网格 → 向量化批量计算（与单点同一 compute，禁双轨）→
     约束过滤（知识库 + UI 覆盖，产出 pass_matrix）→ 裕度/成本排序 →
     （无解时）最小冲突集诊断；
  3. 应用某方案 = 原子写 design + 新 hash + 触发全厂传播重算（增量图执行）；
  4. 全厂联合枚举（跨单元同时寻优）明确为**远期研究项**，
     禁止伪装成本轮功能（服务层显式拒绝多单元请求）；
  5. 汇流加权语义联动：design 工况用 q_design、avg 用 q_avg_daily，
     Kz 取 max（§14.2，修正旧系统固定 Q_design 加权错误）。
- 后果：枚举永远秒级；跨单元寻优留待未来（若做，另立 ADR）。
- 细化归属：M2 枚举+诊断+画布集成。
- R2D 2026-09-02 注记（外审整改#4·向量化规格降级）：决策 2「向量化批量
  计算（与单点同一 compute，禁双轨）」按现状收口为「批量 = 逐行调用同一
  compute（禁双轨实质 = 唯一计算源）」——向量化数组实现为 UF-36 挂账
  增强项。原文保留以存演进记录。

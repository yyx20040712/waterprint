# ADR-008：工艺计算方法路线（调研拍板 2026-08-22）

- 状态：**已接受**（领域专家拍板；调研底稿见会话记录，参数落库随 M2/M3）
- 背景：工程设计无唯一标准答案，四个高分歧单元家族存在多条规范/手册
  路线（负荷法 vs 泥龄法、表面负荷 vs 固体通量、高密池无专门国标、
  污泥产率两法并存于 GB 50014-2021），必须先定主线才能冻结公式组。
- 决策（四项，均含校核侧）：
  1. **AAO 生物池：负荷法主线 + 泥龄校核**——好氧区按 GB 50014-2021
     §7.6.10 容积公式，缺氧区按反硝化公式，厌氧区按 §7.6.39 HRT
     （1~2h）；泥龄 θc=V·X/ΔX 仅作校核输出（11~23d 带内判断硝化/脱氮
     能力，越界出警告而非换算）。依据：GB 50014-2021 §7.6 + HJ 576-2010；
     不采用 DWA-A-131 泥龄法为主线（golden 案例与设计院口径对齐优先）。
  2. **辐流二沉池：清水表面负荷主控 + 固体负荷校核**——A=max(Qmax/q,
     固体负荷校核面积)，q=0.6~1.5 m³/(m²·h)，固体负荷≤150 kg/(m²·d)
     （周进周出≤200），与 AAO 回流比/MLSS 联动。依据：GB 50014-2021
     表 7.5.1 + §7.6.15/7.6.16。固体通量法不作主控（需沉降试验数据）。
  3. **高密沉淀池：仅实现污泥回流型（Densadeg 类）**——斜管清水区
     液面负荷 10~20 m³/(m²·h)、污泥回流比 3%~5%、浓缩区参数带。
     依据：GB/T 50335-2016 §5.4.3 + GB 50013-2018 §9.4.24（给水侧
     同型池成套参数）。Actiflo（微砂型）与磁混凝（T/CECS 636-2019）
     不纳入参数库（矿井水线磁分离为独立单元，见第 4 条边界）。
  4. **污泥产量：经验产率法主线 + 机理法互校**——主线 Sy=Q(S₀−Sₑ)·y/1000
     （y 按工艺查 GB 50014-2021 §8.1.4 表 5：AAO 0.4~0.6、无初沉
     0.85~1.05 等）；互校 ΔX=Y·QΔS−Kd·V·Xv（Y 0.4~0.8、Kd 0.04~0.075，
     θ 温度修正），偏差>20% 出警告（提示核对 SS/BOD 比）。
- 后果：四条主线全部有标准正文背书、golden 对照口径统一；泥龄法/
  固体通量法/Actiflo 等替代路线不实现（列入远期，如需新增走新 ADR）；
  动力学系数（a′/b′/Y/Kd/Kde）取值表归属 `data/coefficients` 数据包。
- 细化归属：M2 市政线公式组冻结（AAO/二沉/高密）；M3 污泥线入口口径。
- I3 注记（2026-08-28，Ruling 九裁②）：出处白名单两类→三类——
  CJJ 131-2009（城镇污水处理厂污泥处理技术规程）纳入污泥线数值
  source 标注（规程级口径，章级不虚构条号——九裁⑤联动）；coefficients
  0.9.0 升级回填（20 键纯 source 改标，value 零变更）。

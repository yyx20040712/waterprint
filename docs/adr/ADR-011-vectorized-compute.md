# ADR-011：向量化 compute 修宪——批量=同源向量路径唯一化（批 13 呈裁草案 2026-09-06）

- 状态：**Proposed（呈裁中）**——修宪批：本 ADR 批复后仍须在实现前对
  AGENTS.md 修订笔再呈裁一道（交接 §四批 13「中途须用户批复」双闸口径）。
- 背景：
  - 宪法 AGENTS.md §13.6 单元包固定结构注记（L172）：「compute.py 唯一
    计算源：批量=逐行 compute 调用（**禁双轨**）；向量化增强挂 UF-36，
    ≤400 行」——条款自带 UF-36 挂账出口，但「批量=逐行调用」的字面
    冻结与向量化（numpy 数组路径）相抵：若 formulas 公共面增批量通道
    且单元 compute 重写为向量实现，同一公式即存在标量/向量两条求值
    实现——字面双轨。
  - UF-36 记档（undefined-features-register.md）已定调防双轨实质：
    「防双轨实质=**唯一计算源**，N=1==单点锁定断言成立」——双轨的
    判据是「是否存在第二条实现」，不是「是否批量」；枚举面
    （enumerate）现行形态=同一 unit.compute 逐网格行驱动，N=1 时与
    单点锁定断言等价。
  - 现状（M2-SOL 锁定架构）：formulas.apply（registry/formulas.py
    L335）=标量强类型唯一求值正门（bindings: Mapping[str, float] →
    float）；13 单元标量守卫已锁定；GR-37（conventions §11）已定义
    向量化数值域错误载体=局部 `np.errstate(divide/over/invalid=
    "raise")` 承接+isfinite 二道网，R2D 降级注记明言「UF-36 向量化
    落地后即为批量路径强制载体」——载体先于路径在册。
  - 性能面：apply 向量化增强挂账口径「万级 <5s 预算探针②」（UF-36
    记档引用 M2-SOL 实现报告实测）——现行逐行形态在万级网格下是否
    达标由设计腿复核探针数据，不达标即本批动因，达标则本批降级挂账。
- 修宪决策（呈裁项）：

| # | 决策 |
|---|------|
| D1 | **防双轨语义重定义**（宪法修订核心）：「禁双轨」判据=唯一求值实现，非禁批量。修订后口径：compute.py 唯一计算源=**同源向量路径**——formulas 公共面增批量正门（apply 数组形态或 apply_batch，设计腿裁），标量调用=N=1 退化形态（薄适配，非第二条实现）；「批量=逐行 compute 调用」字面废止，替换为「批量=向量路径唯一化，N=1 退化等价」 |
| D2 | **等价性铁律沿承升格**：向量化重写不得改变任何可观测语义——13 单元重写逐批过「逐行基线锚」（重写前逐行输出固化为 golden/锁定断言基线）+R1 消息恒等（含 spacing 组别双形态）+golden 三表数值锚+890 常驻回归。双形态并存期=过渡纪律：重写一批、验一批、删该单元标量路径一批，**禁止长期并存**（并存=事实双轨） |
| D3 | **GR-37 载体升格**：errstate 三态 raise+isfinite 二道网从「未来约束」转「批量路径强制载体」；GR-02 与 enumerate NaN 标注列口径分界（GR-37 既有注记）不变；行级域拒口径（compute 领域异常→dims 全 NaN+nan_flag=True 进表，UF-36 已记档）为批量路径行为规格 |
| D4 | **性能预算入册**：万级 <5s（UF-36 挂账口径）→ §18.1 预算表+pytest-benchmark 用例随批登记；探针实测数字（M2-SOL 报告）由设计腿复核引用入设计书 |
| D5 | **影响面与节奏**：13 数值单元重写（numpy 面单元）+32 单元包涟漪（接口相容面，交接 §四口径——设计腿复核确切清单）；大批分批落地（每批≤~4 单元+当批涟漪），每批独立 CI 8/8 |
| D6 | **禁区**：engine_version 语义——向量化重写属实现形态变更，重算结果与逐行基线字节级一致时 engine_version 是否抬版由设计腿呈裁（推荐：抬 patch 位并注记，ReproTriple 可复现性优先）；B12 缓存语义零触碰（CacheKey/重放面不感知向量化） |

- 中途批复闸（交接「中途须用户批复」落点）：
  - **闸1** 本 ADR 批复（修宪方向+D1~D6 口径）；
  - **闸2** 设计书+D 一审+A 二审后、实现笔前——AGENTS.md L172 修订
    笔+conventions GR-37 升格笔（两制度件同笔）呈裁；
  - 闸 2 后进入实现批管道（分批 D5 节奏）。
- 呈裁问题：Q1 修宪方向（D1 防双轨语义重定义）是否认可？Q2 D2 过渡
  纪律（禁止长期并存）是否认可？Q3 D6 engine_version 处理推荐口径
  是否认可？Q4 本批是否在批 14 首样、批 11（视种子裁决）之后启动
  设计腿（批序 Ruling 沿承：14→11→13）？
- 后果：宪法字面从「禁批量」转向「禁第二实现」——枚举面/敏感性面/
  未来万级网格场景获得向量化通道；13 单元重写+32 包涟漪=大批体量
  （多批节奏）；GR-37 载体从纸面转强制；双形态过渡期存在临时维护
  成本（D2 删除纪律封顶）。

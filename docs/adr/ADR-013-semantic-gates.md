# ADR-013：语义门禁词汇面与去除代数不变式（GOV1 2026-09-12）

- 状态：**Accepted**（授权链=《生产级设计审计与建议_GLM5.3汇报》§6 A1/C1
  →总控裁决《审计裁决与治理优化规划_GLM5.3.md》B-1/B-7→本批实施；
  用户常设指令推荐序沿册）。
- 背景：
  - 深度审计（2026-09-12）指出词汇门禁盲区：`UNFINISHED_MARKERS` 仅
    `not implemented/placeholder/TODO/FIXME` 四英文词，中文语境存根全放行；
    并建议把 `未就绪/挂起/占位/未实现/暂不实现/留空待/待实装/待接`
    加封+UNIMPLEMENTED 标记+白名单。
  - 总控复核实测：候选词族在源码 337 处命中——`占位`164（模板占位符
    /SSE 限流槽/几何占位长/占位文案属性=合法过载域词）、`未就绪`151
    （诚实 501 拒绝面带 M2/M3/M4 归属+UF 登记+AU-3 端点测试/UI loading
    态/休眠守卫 reason）、`挂起`21（UI 挂起态/SSE 流挂起测试技法）。
    字面封禁=约 337 处误报；白名单改造=新建 337 条手工豁免登记面
    （与审计 B1 熵减目标自相矛盾）且重写 300+ 处违"架构与代码不要再动"。
  - 同批实证：UF-51 的真缺口不在"无断言"（NP1/NP2 后单元级精确值断言
    在案）而在"无通用不变式"——`out=in×(1−r)` 代数式实测 20 个声明
    removal_refs 的单元（含 r=0 诚实穿流单元）**零偏差**成立。
  - `import_legacy` 定性勘正：审计称"声明端点行为不存在的活体样本"——
    复核 M4 归属注记+ImportNotReadyError→501+端点测试在案，属**已登记
    诚实拒绝**非隐藏空实现。
- 决策：

| # | 决策 | 理由 |
|---|------|------|
| D1 | **零命中中文硬封族入库**：`未实现/待实现/待实装/暂不实现/留空待/待接入` 并入 UNFINISHED_MARKERS（命中即 FAIL）；唯一迁移点=graph/__init__.py 历史注记引述改写 | 六词入库时源码 0 命中（实测）——封"未来新写中文存根"盲区，迁移成本≈0 |
| D2 | **过载域词不封**：`占位/未就绪/挂起/兜底` 不入封禁表 | 337 处合法用法实测在案；封禁产生的误报面/豁免登记面＞收益；诚实拒绝面已有四重机器/契约保障（UF 登记+归属+501 映射+端点测试） |
| D3 | **通用代数不变式常驻**：`core/tests/units_lib/test_removal_semantics.py` 参数化覆盖 discover_units() 全部声明 removal_refs 的单元（新单元入册自动纳入），断言 `out[K]=in[K]×(1−r[K])`（r 自 data/coefficients 真源）+r∈[0,1] 域守卫 | 一次封死 UF-51 全类（声明去除而透传/率用错/漏键）；实测 20 单元零偏差；变异验证 20 红（断言强度实证）；经正门 discover_units+app._unit_params（宪法 §1 装配点纪律） |
| D4 | **skip==0 落 CI 面**（ci.yml core/server pytest 步骤 grep 非零 skipped 即 FAIL），不做 run_gates 第 12 项 | 与覆盖率 fail_under 同构先例（门禁只在 CI 面）；run_gates 定位零依赖快检，pytest 属 venv/CI 面——不破此边界 |
| D5 | **注释配平禁令入 GR-42③**（禁止增删纯注释配平行数贴预算） | e7f2c54 先例=门禁诱导变形；500 行无豁免制维持（裁决 B-5：豁免面=新登记面+稀释预算严肃性，驳回） |
| D6 | **33 份 properties.py 保留不删**，C1-续批逐单元转实内容 | 2026-09-02 R2D 收口已明确"结构预留件"定位并主动移出收集；内含各单元物理性质清单=领域知识；删除=高扰动（33 文件+check_structure+锁面 94 键）低收益 |

- 后果：
  - 正面：中文存根盲区封堵（D1）；UF-51 类语义缺陷从"靠人补测试"升级
    为"机器常驻断言"（D3）；skip 回潮机器拦截（D4）；testing.md 两处
    失实勘正（收集口径/锁面范围——实测 270=139+39+94 分解）。
  - 代价：新增语义测试入锁面（[HUMAN-LOCK] 沿册规程 270→271）；诚实
    拒绝面仍依赖四重纪律自觉组合（未做机器校验链接——"拒绝面↔UF 登记
    双向核对"评估为信号噪声比不佳，实测 24 处缺注记命中过半为误报，
    挂账路线图观察）。
  - 不做清单（裁决固化）：中文过载词词汇封禁/白名单；500 行豁免清单；
    架构与代码重构（生产级冻结）。

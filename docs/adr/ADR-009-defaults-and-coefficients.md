# ADR-009：工艺参数默认值与系数库层级（B 级拍板 2026-08-22）

- 状态：**已接受**（领域专家整批采纳建议默认值；数值落 `data/coefficients`
  随 M1 加载器实现，录入时逐条挂出处键）
- 背景：ADR-008 定了四条方法主线；B 级为 16 项单元级默认值与库层级，
  与"初始参数不保证可行、须工业级调节指引"（docs/business-logic.md §4）
  共同构成计算业务逻辑的参数基座。
- 决策（16 项，编号 B1~B16 与调研清单一一对应）：

| # | 决策 |
|---|------|
| B1 | CASS 默认 4h 周期 = 进水/曝气 2h + 沉淀 1h + 滗水 1h，时段可调（HJ 577-2010 附录 A 负荷法定容积） |
| B2 | 沉砂池维持旋流（市政）+ 平流（矿井水）；曝气型不建（远期） |
| B3 | 调节池简化 HRT 法主线（市政 6~12h）；逐时曲线法可选输入模式 |
| B4 | 初沉池内置"超越/间歇运行"开关（AAO 碳源矛盾，联动 B5 碳源校核） |
| B5 | V 型滤池以 GB 50014-2021 §7.11.8 为主参数库（滤速 5~8 m/h、周期 12~24h），构造回引 GB 50013-2018 §9.5 |
| B6 | 紫外设计剂量默认 20~25 mJ/cm²；老化/结垢系数双档：有验证 0.85/0.9、无验证 0.5/0.6 |
| B7 | 巴歇尔槽国内公制七档喉宽（0.25~3.0 m）+ 自由流设计 + 淹没度超限报警；C/n 系数按 CJ/T 3008.3-1993 录入 |
| B8 | 泵房：台数 2~8、污水泵房必设备用、集水池≥最大泵 5min 出水量、安全水头 0.3~0.5 m（GB 50014-2021 第 6 章） |
| B9 | 出水标准库：GB 18918-2002 全分级 + 2026-03-01 修改单 + GB 3838-2002；地方准 IV 类为可扩展数据不内置 |
| B10 | 矿井水"执行标准→反推设计出水"可选模块（GB 20426 排放 / GB/T 18920-2020 回用 / GB 3838 III 类从严） |
| B11 | 磁分离参数优先级：T/CECS 636-2019 > 装备团标 > 厂商样本；磁种回收率默认 99% 档 |
| B12 | 消化产气量按 VS 去除计 0.75~1.0 Nm³/kgVS去除（镇江 0.77 为锚点）；温度缺省 35℃（33~38 可调） |
| B13 | 脱水 PAM 分档：带机 3~5、离心 1.2~1.5 kg/tDS；板框双调理路线（石灰+铁盐 / 纯 PAM）都建 |
| B14 | 干化热耗缺省 3000 kJ/kgH₂O（红线 <3300）；出泥档位 40%/30%/10% |
| B15 | 污泥输送按清水水力×修正系数（不建流变模型）；流速 1.0~1.5 m/s，表 5.2.8 校核 |
| B16 | 系数库层级：GB 50014-2021 条文说明 > 给水排水设计手册第 5 册 > Metcalf（仅参照） |

- 附注（标准版本事实，引用表据此更新）：GB 50265-2010→**2022**；
  GB/T 19837-2005→**2019**；GB 18918-2002 增 2026-03-01 修改单；
  `GB/T 50806`（矿井水利用设计规范）**不存在**、`GB/T 38097-2019`
  与煤矿无关（两条证伪）；矿井水线补充现行 **GB/T 41019-2021
  《矿井水综合利用技术导则》** 与 GB/T 19223-2015、GB/T 31392-2022。
- 后果：全部默认值带出处键入 `data/coefficients`（版本化），代码零内联
  数值（scripts/check_magic_numbers.py 门禁强制）；替换/加严值 = 数据包
  新版本，可复算三元组自动失效旧结果。
- 细化归属：M1 coefficients 加载器 + assumptions 注入链；M2/M3 逐单元落值。

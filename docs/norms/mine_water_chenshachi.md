## 公式表（KC-F1~KC-F10，DSL 公式串供 FormulaSpec 直用）

> DSL 语法子集同市政表；L/B 离散化（0.5 m / 0.1 m 档）不入 DSL。

| formula_id | 表达式（受限 DSL） | 变量 | 系数列（factor.mine_chenshachi.*） | 出处 |
|-----------|--------------------|------|-----------------------------------|------|
| KC-F1 | `l_cell_raw = v_h * t_stay` | v_h 设计水平流速 m/s；t_stay 停留 s（l_cell 0.5 m 档向上取整） | velocity_band.min/max、retention_band.min/max | 给水排水设计手册（平流沉砂池） |
| KC-F2 | `a_cross = q_design / (n * v_h)` | n 格数（声明面离散档） | — | 给水排水设计手册（多格） |
| KC-F3 | `b_raw = a_cross / h2` | h2 有效水深 m（b_raw ≥ cell_width.min，0.1 m 档向上取整得 B） | depth_band.min/max、cell_width.min | 给水排水设计手册（断面水深） |
| KC-F4 | `v_h_act = q_design / (n * b * h2)` | 实际水平流速校核（带内） | velocity_band.min/max | 给水排水设计手册 |
| KC-F5 | `v_sand = q_avg_daily * x_sand / 1000000` | x_sand 沉砂量 m³/10⁶m³（高 SS 矿井水高于市政 30 档） | sand_yield_x | 给水排水设计手册（沉砂量，可沉组分折算） |
| KC-F6 | `v_hopper = v_sand * t_clean * safety` | t_clean 清砂周期 d（声明面默认 2）；safety 贮砂安全系数 | hopper.safety | 给水排水设计手册（砂斗容积） |
| KC-F7 | `l_weir = n * (l_cell + 2 * b)` | 出水堰可用堰长（池壁两侧+末端） | — | 给水排水设计手册（薄壁堰） |
| KC-F8 | `q_weir = q_design * 1000 / l_weir` | 堰负荷校核 L/(s·m)（≤ weir_load.max） | weir_load.max | 给水排水设计手册（出水堰负荷） |
| KC-F9 | `h_total = h_super + h2` | h_super 超高 | superheight | 给水排水设计手册 |
| KC-F10 | `v_concrete = l_cell * b * h_total * n * wall_coef` | 概算口径混凝土量 | wall_thickness_coef | 给水排水设计手册（概算口径） |

## 水质衔接式（矿井水线水质链）

- 入流（tiaojiechi 表出流）：SS_in = **800.0 mg/L**、COD_in = **200.0 mg/L**
- 出流：SS_out = 800×(1−0.15) = **680.0 mg/L**；COD 穿流 = **200.0 mg/L**
  （沉砂仅除砂粒组分，COD 键不建——非混凝沉淀滤池段）
- NH3N/TN/TP/TDS/pH 穿流不变
- **与市政同名构筑物边界差异**：市政 chenshachi（municipal/chenshachi，
  docs/norms/chenshachi.md）为**旋流**沉砂池（表面负荷 150~200
  m³/(m²·h)、停留 25~60 s、径深比 2.0~2.5），SS 去除 0.10——本表为
  **平流**型（水平流速 0.15~0.30 m/s 主控、浅池 0.4~1.2 m），SS 去除
  0.15（高 SS 进水砂粒组分高）；出水目标（市政=初沉/调节进水；矿井水=
  混凝反应进水）与规范依据（市政 GB 50014-2021；矿井水 GB/T 41019-2021）
  不同——同 ID 不同型构筑物，键空间经 mine_ 限定物理隔离（§14.3）。

## 手算算例（2 组典型工况）

主算例输入：Q_design = 0.7610416667、Q_avg_daily = 43836.0、n = 8、
v_h = 0.25、t_stay = 60 s、h2 = 0.5 m、h_super = 0.3、x_sand = 60、
t_clean = 2 d、safety = 1.5、wall_coef = 0.35。

| 量 | 手算过程摘要 | 期望值 |
|----|--------------|--------|
| l_cell（KC-F1） | 0.25×60=15.0 → 0.5 m 档 | **15.0 m** |
| a_cross（KC-F2） | 0.7610416667/(8×0.25) | **0.3805208333 m²** |
| B（KC-F3） | 0.3805208/0.5=0.7610416667 → 0.1 m 档（≥0.6） | **0.8 m** |
| v_h_act（KC-F4） | 0.7610416667/(8×0.8×0.5)（带 0.15~0.30 内，合格） | **0.2378255208 m/s** |
| v_sand（KC-F5） | 43836×60/10⁶ | **2.63016 m³/d** |
| v_hopper（KC-F6） | 2.63016×2×1.5 | **7.89048 m³**（全厂清砂周期贮砂） |
| l_weir（KC-F7） | 8×(15.0+2×0.8) | **132.8 m** |
| q_weir（KC-F8） | 761.0416667/132.8（≤10 合格） | **5.7307354418 L/(s·m)** |
| h_total（KC-F9） | 0.3+0.5 | **0.8 m** |
| v_concrete（KC-F10） | 15.0×0.8×0.8×8×0.35 | **26.88 m³**（概算） |

副算例（带下限工况）：v_h = 0.20、t_stay = 45 s（其余同主算例）：
l_cell = 9.0 → **9.0 m**；a_cross = **0.4756510417 m²**；B =
0.9513020833 → **1.0 m**；v_h_act = **0.1902604167 m/s**；l_weir =
**88.0 m**；q_weir = **8.6482007576 L/(s·m)**（≤10 合格）；
v_concrete = **20.16 m³**。

# gaomidu 手算对照表（golden 期望值唯一来源）【已起草待追认】

> 状态：**已起草待追认**——数据策略 v2（工程常用范围口径，GB 国标 +
> 《给水排水设计手册》，见 AGENTS §14）；公式路线 = ADR-008 ③ 逐字落地：
> **仅污泥回流型高密度沉淀池（Densadeg 类）**——斜管清水区液面负荷
> 10~20 m³/(m²·h) 主控、污泥回流比 3%~5%、浓缩区参数带；Actiflo
> （微砂型）与磁混凝不纳入。本表数值出处仅标 GB 国标（含
> GB/T 50335-2016，ADR-008 裁决合法）与《给水排水设计手册》两类。

## 单元信息

- UNIT_ID：gaomidu（新系统身份 municipal/gaomidu）
- 中文名 / 业务线：高密度沉淀池（污泥回流型，Densadeg 类）/ 市政污水处理
- 结构组成：快速混合区（PAC）+ 机械絮凝区（PAM）+ 斜管沉淀/清水区 +
  污泥浓缩区 + 污泥回流（浓缩区→快速混合器）
- 规范依据（主）：GB/T 50335-2016 §5.4.3（污水再生利用工程设计：
  高密斜管清水区液面负荷）+ GB 50013-2018 §9.4.24（给水侧同型池
  成套参数，ADR-008 双源标记）；《给水排水设计手册》混合/絮凝 G 值
  法（P=μG²V）与斜管沉淀常用值
- 流量口径：沉淀区水力与混合/絮凝区容积按**最高时设计流量**
  Q_design = 0.56325 m³/s（= 34760.7/86400 × 1.4，与 docs/norms 各表
  同源口径）；药剂耗量与干泥量按**平均日流量** Q_avg_daily = 34760.7 m³/d

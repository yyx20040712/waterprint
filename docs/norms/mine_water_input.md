## 公式表（KI-F1~KI-F7，DSL 公式串供 FormulaSpec 直用）

> DSL 语法子集：`OUT = RHS`，算术 + 白名单函数 {min,max,abs,sqrt,log10}；
> π 以内联常量 3.14159265 出现（公式条文常量）。

| formula_id | 表达式（受限 DSL） | 变量 | 系数列（factor.mine_input.*） | 出处 |
|-----------|--------------------|------|------------------------------|------|
| KI-F1 | `q_design = q_avg_daily * kz / 86400` | q_avg_daily 平均日 m³/d；kz 总变化系数 | — | GB/T 41019-2021（水量口径，条号待核对） |
| KI-F2 | `q_avg_h = q_avg_daily / 24` | — | — | 同上 |
| KI-F3 | `v_inlet = (q_avg_daily / 86400) / (3.14159265 / 4 * (dn_inlet / 1000) ** 2)` | dn_inlet 进水管径 mm（校核：管内平均时流速经济流速带内） | — | 给水排水设计手册（第 3 册 城镇给水）管流常用 |
| KI-F4 | `z_pipe_bottom = z_water_inlet - dn_inlet / 1000` | z_water_inlet 进水水面标高 m | — | 给水排水设计手册（标高衔接惯例） |
| KI-F5 | `z_water = z_water_inlet - h_loss` | h_loss 进水水头损失 m | elevation_loss | 给水排水设计手册（进水头部经验损失） |
| KI-F6 | `z_bottom = z_water - h_pool` | h_pool 井下提升有效水深 m（声明面构造默认 3.0） | — | 给水排水设计手册（第 3 册 城镇给水） |
| KI-F7 | `freeboard = z_ground - z_water` | z_ground 地面标高 m（校核 ≥ freeboard.min） | freeboard.min | GB/T 41019-2021（厂区布置，条号待核对） |

## 手算算例（2 组典型工况）

主算例（旧案例参数交叉对照）输入：Q_avg_daily = 43836.0、Kz = 1.5、
z_water_inlet = 100.0、z_ground = 102.0、DN_inlet = 800、h_loss = 0.2、
h_pool = 3.0。

| 量 | 手算过程摘要 | 期望值 |
|----|--------------|--------|
| q_design（KI-F1） | 43836×1.5/86400 | **0.7610416667 m³/s**（=2739.75 m³/h） |
| q_avg_h（KI-F2） | 43836/24 | **1826.5 m³/h** |
| v_inlet（KI-F3） | 0.5073611/(3.14159265/4×0.8²)（经济流速带内） | **1.0093628607 m/s** |
| z_pipe_bottom（KI-F4） | 100−0.8 | **99.2 m** |
| z_water（KI-F5） | 100−0.2 | **99.8 m** |
| z_bottom（KI-F6） | 99.8−3.0 | **96.8 m** |
| freeboard（KI-F7） | 102−99.8（≥0.3 合格） | **2.2 m** |

副算例（小流量脉动工况）：Q_avg_daily = 30000、Kz = 1.4、DN_inlet = 700：
q_design = 30000×1.4/86400 = **0.4861111111 m³/s**；q_avg_h = **1250.0 m³/h**；
v_inlet = 0.3472222/(3.14159265/4×0.49) = **0.9007953379 m/s**；
z_pipe_bottom = **99.3 m**（z_water_inlet 同 100）。

## 手算算例（1~3 组典型工况）

> 输入源与流量口径同 `docs/norms/cugeshan.md`：Q_design(派生) = 0.56325 m³/s、Q_avg_daily = 34760.7 m³/d、Kz = 1.4。
> 单元参数取旧系统市政案例文件（`resources/yyx.ddesign.json`）实际值：
> n=3、b=8 mm、α=70°、h=0.6 m、v=0.8 m/s、v₁=0.7 m/s、s=3 mm、bar_shape=0（矩形 β=2.42）。
> 全部期望值为 **AI 草算，待领域专家复核**。

### 算例 1：golden 派生口径（主算例，未来 test_compute.py 期望值来源）

| 量 | 手算过程摘要 | 期望值 |
|----|--------------|--------|
| q（XG-F1） | 0.56325/3 = 0.18775 m³/s | 0.18775 m³/s（187.75 L/s） |
| n_gap（XG-F2） | √(sin70°) = 0.96938；0.18775×0.96938 = 0.18200；分母 0.008×0.6×0.8 = 0.00384；0.18200/0.00384 = 47.40 → ceil = 48 | **48 个** |
| B（XG-F3） | 0.003×47 + 0.008×48 + 0.2 = 0.141+0.384+0.2 = 0.725 → ceil(7.25)×0.1 | **0.8 m** |
| B₁（XG-F4） | 0.18775/(0.6×0.7) = 0.44702 → ceil(4.47)×0.1 | **0.5 m** |
| v_checked（XG-F5） | 0.18200/(0.008×0.6×48) = 0.18200/0.2304 = 0.7899 m/s（带 0.6~1.0 内，合格） | **0.790 m/s** |
| v₁_checked（XG-F6） | 0.18775/(0.6×0.5) = 0.6258 m/s（合格） | **0.626 m/s** |
| ξ（XG-F7） | (3/8)^(4/3) = 0.375^1.3333 = 0.27042；ξ = 2.42×0.27042 = 0.65442 | **0.6544** |
| h₁（XG-F8） | h₀ = 0.65442×0.7899²/19.62×sin70° = 0.65442×0.62399/19.62×0.93969 = 0.019558；h₁ = 3×0.019558 = 0.05867 m（≤0.3 合格） | **0.0587 m** |
| H（XG-F9） | 0.6+0.05867+0.3 = 0.95867 → ceil(9.59)×0.1 | **1.0 m** |
| L（XG-F10） | tan70°=2.74748；L₁=(0.8−0.5)/(2×2.74748)=0.05460；L₂=0.02730；(0.2+0.6)/2.74748=0.29119；L=0.05460+0.02730+1.0+0.5+0.29119=1.87309 → ceil(18.73)×0.1 | **1.9 m** |
| W（XG-F11） | 34760.7×0.08/1000 = 2780.856/1000 | **2.7809 m³/d** |
| 清渣方式（XG-F12） | 2.7809 > 0.2 | **机械清渣** |
| 栅渣 DS（XG-F13） | 2.7809×(1−0.80)×1000 = 2.7809×200 | **556.2 kg/d**（P=0.80，VS=0.85） |

### 算例 2：旧系统 0.57 口径（对照算例）

Q_design = 0.57 m³/s：q = 0.19 m³/s；
n_gap：0.19×0.96938/0.00384 = 47.96 → ceil = **48**（同算例 1）；
B、B₁、H、L 与算例 1 相同（0.8 / 0.5 / 1.0 / 1.9 m）；
v_checked = 0.19×0.96938/0.2304 = **0.799 m/s**；v₁_checked = 0.19/0.3 = **0.633 m/s**；
h₁ = 3×0.65442×0.799²/19.62×0.93969 = **0.0601 m**；
W = 0.57×86400×0.08/(1.4×1000) = **2.8142 m³/d**（DS = 562.8 kg/d）。

## 手算主算例（golden 全厂口径，未来 test_compute.py 期望值来源）

输入：Q_design = 0.56325 m³/s（引擎 q_design 精确值 = 0.5632520833，
即 563.2521 L/s）、Q_avg_daily = 34760.7 m³/d（402.3229 L/s）、
b_throat = 0.75 m（b075 档：C = 1772、n = 1.557、hmin = 0.06、
hmax = 0.75、scrit = 0.6）、hb_design = 0.25 m、loss_ratio = 0.25。

|----|--------------|--------|

| q_meas（BL-F1） | 1772×0.385883^1.557（=q_avg_ls 往返闭环） | **402.3229 L/s** |
| b1（BL-F4） | 1.2×0.75+0.48 | **1.38 m** |
| l1（BL-F5） | 1.2+0.5×0.75 | **1.575 m** |

## 追认点（本表工程裁量，领域专家批量追认清单）

1. **B7 七档枚举面口径**：简报/业务逻辑枚举值 0.25/0.5/0.75/1.0/1.25/
   1.5/2.0 中 0.5/1.25/2.0 非手册标准喉宽档——本表按"最近标准档"映射
   为 0.45/1.20/2.10（七档=0.25/0.45/0.75/1.00/1.20/1.50/2.10）；
   **最终枚举面归领域专家裁定**（保留简报原值则 C/n 需另立非标档依据）。
2. **构造尺寸比回归系数**：B1=1.2b+0.48、L1=1.2+0.5b、B2=b+0.3 系
   手册标准型构造尺寸表（0.25~2.40 m 共 12 行）的精确线性回归（逐行
   验证偏差=0）；L=0.60/L2=0.92/N=0.23/K=0.08 为标准型常数——回归
   式与常数表以 CJ/T 3008.3-1993 正式文本逐字核对（Q3 挂账，追认）。
3. **C/n 系数表数值面**：七档 C/n/scrit/hmin/hmax 从手册流量计安装/
   检定口径表录入（Q 单位 L/s）；**CJ/T 3008.3-1993 正式文本核对**
   （business-logic §10 Q3）——核对前数值面全部待追认。
4. **下游水深设计假定**：hb_design = 0.25 m 系出口自由出流布置假定
   （保证 σ<0.6）；实际淹没度随排放口水位变化——运行面校核非本表面。
5. **槽身水头损失比**：loss_ratio = 0.25 为估算口径（0.2~0.3 带内），
   精确水损随流态而变——与 elevation_loss = 0.15 m（链输入经验值）
   双轨并存语义：前者为槽身计算值、后者为高程链输入值，追认时核对
   归一（是否合并单键）。

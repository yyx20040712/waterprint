## 水质衔接式（矿井水线水质链：SS/COD 双指标面）

- 入流（input 表出流）：SS_in = **800.0 mg/L**、COD_in = **200.0 mg/L**
- 出流（零去除穿流）：SS_out = 800.0×(1−0.0) = **800.0 mg/L**；
  COD_out = **200.0 mg/L**

- BOD5 不建键（B/C=0.025 无生化性，全线同口径——见表尾注记）
- **与市政同名构筑物边界差异**：市政 tiaojiechi（municipal/tiaojiechi，
  docs/norms/tiaojiechi.md）hrt_band 6~12 h、depth_band 4.0~6.0 m、
  搅拌 4~8 W/m³（取 6）——本表 hrt 8~12/depth 3.0~5.0/搅拌 8.0 三参数
  带独立起草（井下脉动+高 SS+地下式布置），出水目标（市政=后续深度
  处理进水；矿井水=沉砂池进水）与规范依据（市政 GB 50014-2021；
  矿井水 GB/T 41019-2021）均不同——§14.3 物理隔离的可审计面。

## 手算算例（2 组典型工况）

主算例输入：Q_avg_daily = 43836.0、n = 16、t_reg = 8.0 h、h2 = 3.0 m、
ratio_lb = 3.0、h_super = 0.5 m、w_stir = 8.0 W/m³、v_out = 1.5 m/s、
wall_coef = 0.35。

| 量 | 手算过程摘要 | 期望值 |
|----|--------------|--------|
| v_total（KT-F1） | 43836×8/24 | **14612.0 m³** |
| v1（KT-F2） | 14612/16 | **913.25 m³** |
| a1（KT-F3） | 913.25/3.0 | **304.4166666667 m²** |
| B（KT-F4） | √(304.4167/3.0)=10.0733421575 → 0.5 m 档 | **10.5 m** |
| L（KT-F5） | 304.4167/10.5=28.9920634921 → 0.5 m 档 | **29.0 m** |
| a_act（KT-F6） | 10.5×29.0 | **304.5 m²** |
| v_act_total（KT-F7） | 304.5×3.0×16（≥14612 合格） | **14616.0 m³** |
| t_reg_act（KT-F8） | 14616×24/43836（带 8~12 内，合格） | **8.0021899808 h** |
| p_stir（KT-F9） | 14616×8/1000（全池） | **116.928 kW** |
| d_out（KT-F10） | √(4×0.5073611/(3.14159265×1.5))=0.656… → 0.05 m 档 | **DN700（0.70 m）** |
| h_total（KT-F11） | 0.5+3.0 | **3.5 m** |
| v_concrete（KT-F12） | 304.5×3.5×16×0.35 | **5968.2 m³**（概算） |

π 精度注记（KT-F10）：手算过程摘要列与 DSL 串内联 3.14159265 为截断 π；
实现侧 d_out_raw 按 math.pi 精度算得（差约 4e-10，DN 0.05 m 档取整结果
不变——在测试容差内），实现绑定 math.pi 与期望值一致，本注记不改数值。

副算例（带上限工况）：t_reg = 12.0 h（其余同主算例）：v_total =
**21918.0 m³**；v1 = **1369.875 m³**；a1 = **456.625 m²**；B =
12.3372741452 → **12.5 m**；L = 456.625/12.5=36.53 → **37.0 m**；
a_act = **462.5 m²**；v_act_total = **22200.0 m³**；t_reg_act =
**12.1543936491 h**（越带上限 12——构造取整放大所致，校核按 ≥v_total
合格口径，贴限记录归追认点 3）；p_stir = **177.6 kW**；DN = **700**。

## 公式表（CC-F1~CC-F18，DSL 公式串供 FormulaSpec 直用）

> DSL 语法子集：`OUT = RHS`，算术 + 白名单函数 {min,max,abs,sqrt,log10}；
> 取整（ceil）不入 DSL——离散化后的值（D、d_center、h4、h_total）作为
> 下游公式输入符号。π 以内联常量 3.14159265 出现（公式条文常量）。

| formula_id | 表达式（受限 DSL） | 变量 | 系数列（factor.chuchenchi.*） | 出处 |
|-----------|--------------------|------|-------------------------------|------|
| CC-F1 | `q1h = q_design * 3600 / n` | q_design 最高时流量 m³/s；n 池数（单池 q1 = q_design/n） | — | GB 50014-2021 §6.5（沉淀池） |
| CC-F2 | `f_req = q1h / q_prime` | q_prime 表面水力负荷 m³/(m²·h) | surface_load_band.min/max | GB 50014-2021 §6.5；给水排水设计手册 |
| CC-F3 | `d_raw = sqrt(4 * f_req / 3.14159265)` | — | — | 同上 |
| CC-F4 | `f_act = 3.14159265 * D ** 2 / 4` | D 池径 m（按 0.5 m 档向上取整后） | — | 同上 |
| CC-F5 | `q_prime_act = q1h / f_act` | — | surface_load_band.min/max 校核 | 同上 |
| CC-F6 | `h2 = q_prime_act * t_settle` | t_settle 沉淀时间 h | retention_band.min/max | GB 50014-2021 §6.5 |
| CC-F7 | `ratio_dh2 = D / h2` | — | ratio_dh2_band.min/max；depth_band.min/max | 给水排水设计手册（辐流池径深比常用带） |
| CC-F8 | `d_center_raw = sqrt(4 * q1 / (3.14159265 * v_center))` | v_center 中心管流速 m/s（d_center 按 0.1 m 档向上取整） | center_velocity | 给水排水设计手册（工程常用 0.2~0.5） |
| CC-F9 | `q_weir = q1 * 1000 / (2 * 3.14159265 * (D - 1))` | 周边双侧出水堰（堰长 L = 2π(D−1) m） | weir_load.max | GB 50014-2021 §6.5（沉淀池堰负荷） |
| CC-F10 | `s_dry_1 = q_avg_daily * (ss_in - ss_out) / (1000 * n)` | ss_in/ss_out 进出流 SS mg/L（单池干泥量 kg/d） | —（η 取 removal.chuchenchi.ss.*） | GB 50014-2021 §6.5（初沉 SS 去除 40%~60%） |
| CC-F11 | `s_wet_1 = s_dry_1 / ((1 - p_moisture) * 1000)` | p_moisture 初沉污泥含水率 | sludge.moisture | 给水排水设计手册（初沉污泥 0.95~0.97） |
| CC-F12 | `v_need = s_wet_1 * t_sludge` | t_sludge 贮泥（排泥）周期 d | —（校核带 1~2 d） | GB 50014-2021 §6.5（排泥周期） |
| CC-F13 | `v1_hopper = 3.14159265 * h5 / 3 * (r1 ** 2 + r1 * r2 + r2 ** 2)` | r1/r2 泥斗上/下口半径 m；h5 斗高 m | — | 给水排水设计手册（圆台容积，工程常用构造） |
| CC-F14 | `h4_raw = i_slope * (D / 2 - r1)` | i_slope 池底坡度（h4 按 0.1 m 档向上取整） | bottom_slope | 给水排水设计手册（工程常用 0.05） |
| CC-F15 | `v2_cone = 3.14159265 * h4 / 3 * ((D / 2) ** 2 + D / 2 * r1 + r1 ** 2)` | 池底坡锥台容积 | — | 同上 |
| CC-F16 | `v_storage = v1_hopper + v2_cone` | 污泥区总容积（≥ v_need 校核） | — | 同上 |
| CC-F17 | `h_total_raw = h_super + h2 + h_buf + h4 + h5` | h_super 超高；h_buf 缓冲层（h_total 按 0.1 m 档向上取整） | superheight；buffer_h3 | 给水排水设计手册（超高 0.3、缓冲层 0.3，工程常用） |
| CC-F18 | `v_concrete = 3.14159265 * (D / 2) ** 2 * h_total * n * wall_coef` | 概算口径混凝土量 | wall_thickness_coef | 给水排水设计手册（概算口径，辐流圆形池 0.4 工程常用） |

构造参数（泥斗 r1=1.8 m、r2=0.8 m、h5=1.5 m；超高 0.3 m；缓冲层 0.3 m；
池底坡 0.05）为单元 manifest 声明面默认值（工程常用构造，出处给水排水设计手册）。

出水堰构造默认（显式化）：周边双侧出水堰环形集水槽，堰长 L = 2π(D−1) m
（见 CC-F9）——设计假定（大池径下双圈齿形堰系手册认可的加大堰长措施），
该构造决定堰负荷校核合格性。单侧口径敏感性：若按单侧周边堰
（L = π(D−1)），q_weir ≈ 3.90 L/(s·m) > 2.9 超限——堰构造口径（保持双侧
默认或改单侧）由领域专家追认裁定。
堰圈直径口径统一说明：本表堰圈中心线取 D−1、erchunchi 表取 D（两表口径
不对称系起草取舍）；互换口径不翻转合格性（本表按 2πD 计 q_weir ≈ 1.87
仍 ≤2.9；二沉表按 2π(D−1) 计 ≈ 1.12 仍 ≤1.7）。

## 水质衔接式（全厂去除链，上游 = 粗格栅→细格栅→旋流沉砂池）

- SS_in = 237×(1−0.05)×(1−0.08)×(1−0.10) = **186.4242 mg/L**
  （0.05/0.08/0.10 = removal.{cugeshan,xigeshan,chenshachi}.ss.mod_default）

  **123.2996**；COD_out = 285.6232×0.70 = **199.9362**（衔接下游 AAO 表）

## 手算主算例（golden 全厂口径，未来 test_compute.py 期望值来源）

输入：Q_design = 0.56325 m³/s（Q_avg_daily = 34760.7 m³/d，Kz = 1.4）、
n = 2、q' = 2.3 m³/(m²·h)、T = 1.2 h、v_center = 0.3 m/s、P = 0.96、
T_sludge = 2 d、r1 = 1.8 m、r2 = 0.8 m、h5 = 1.5 m、h_super = 0.3 m、
h_buf = 0.3 m、i_slope = 0.05；水质见衔接式。

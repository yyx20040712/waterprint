> 状态：**已起草待追认**——数据策略 v2（工程常用范围口径，GB 国标 +
> 《给水排水设计手册》，见 AGENTS §14）；公式路线 = ADR-008 ②逐字落地：

## 单元信息

- UNIT_ID：erchunchi（新系统身份 municipal/erchunchi）

- 规范依据（主）：GB 50014-2021 表 7.5.1（清水表面负荷 0.6~1.5

  ≤200）；《给水排水设计手册（第 5 册 城镇排水）》二沉池几何/堰负荷/

  回流比/MLSS 联动（R = 100%、X = 4000 mg/L）

## 公式表（EC-F1~EC-F15，DSL 公式串供 FormulaSpec 直用）

> DSL 语法子集：`OUT = RHS`，算术 + 白名单函数 {min,max,abs,sqrt,log10}；
> max 为白名单函数（面积主控取大）。取整不入 DSL——离散化后的值
> （D、d_center、h4、h_total）作为下游公式输入符号。

| EC-F2 | `a_q = q1h / q_nom` | q_nom 名义清水表面负荷 m³/(m²·h) | surface_load_band.min/max | GB 50014-2021 表 7.5.1 |
| EC-F3 | `m_solid = (1 + r_external) * q1h * 24 * x_mlss / 1000` | r_external 外回流比（联动 AAO）；x_mlss MLSS mg/L | —（联动 factor.aao.r_external_band） | GB 50014-2021 §7.6.15/§7.6.16 |
| EC-F4 | `a_solid = m_solid / g_max` | g_max 固体面积负荷上限 kg/(m²·d) | solid_load.center_inlet（周进周出用 peripheral_inlet） | GB 50014-2021 §7.6.15/§7.6.16 |
| EC-F5 | `a_tank = max(a_q, a_solid)` | 主控面积 = 两者取大（清水负荷与固体负荷双控） | — | GB 50014-2021 表 7.5.1 + §7.6.15/§7.6.16 |

| EC-F9 | `g_act = m_solid / a_act` | 实际固体面积负荷校核 | solid_load.center_inlet | GB 50014-2021 §7.6.15/§7.6.16 |

出水堰构造默认（显式化）：周边双侧出水堰环形集水槽，堰长 L = 2πD m
（见 EC-F11）——设计假定（大池径下双圈齿形堰系手册认可的加大堰长措施），

由领域专家追认裁定。

系起草取舍）；互换口径不翻转合格性（本表按 2π(D−1) 计 q_weir ≈ 1.12
仍 ≤1.7；初沉表按 2πD 计 ≈ 1.87 仍 ≤2.9）。

## 水质衔接式（全厂去除链，上游 = AAO 表；混合液另载）

- 流量：单池清水口径 q1 = 0.281625 m³/s；含回流混合液 (1+R)×q1 =
  0.56325 m³/s（R = 100%，联动 AAO 表 AO-F13）
- 混合液 SS（sizing 口径）：SS = X_MLSS = **4000 mg/L**（AAO 设计参数，
  非水质链乘积——固液分离由 EC-F3/F9 固体负荷公式承载）
- 水质链口径（衔接 AAO 表出质）：BOD5_in = 123.2996×(1−0.90) =
  **12.32996 mg/L**；COD_in = 199.9362×(1−0.85) = **29.99043 mg/L**；
  SS_in = 93.2121×(1−0.90) = **9.32121 mg/L**
- 出流（全厂出水）：BOD5_eff = 12.32996×0.80 = **9.863964 mg/L**（≤10
  一级 A 合格）；COD_eff = 29.99043×0.85 = **25.49187 mg/L**（≤50 合格）；
  SS_eff = 9.32121×0.50 = **4.660605 mg/L**（≤10 合格）
- 达标口径注记：本批去除链承载仅 BOD5/COD/SS 三指标（上行达标结论限于
  此三指标）；TN/NH3N/TP 去除归后续批承载——TN_eff = 15 mg/L 系设计假定
  （一级 A 出水标准数据条目，见 aao 表），非本链计算值
- 语义注记：removal.erchunchi.ss 为水质链槽位（对上游链残余 SS 的补充
  去除，工程常用）；MLSS 的固液分离不经此键（见上 sizing 口径）

## 手算主算例（golden 全厂口径，未来 test_compute.py 期望值来源）

输入：Q_design = 0.56325 m³/s、n = 2、q_nom = 1.2 m³/(m²·h)、G_max = 150
kg/(m²·d)、X = 4000 mg/L、R = 100%、v_center = 0.3 m/s、h2 = 3.0 m、
h_super = 0.3 m、h_buf = 0.3 m、i_slope = 0.05、r_pit = 1.0 m。

| 量 | 手算过程摘要 | 期望值 |
|----|--------------|--------|
| q1h（EC-F1） | 0.56325/2 = 0.281625 m³/s；×3600 | **1013.85 m³/h** |
| a_q（EC-F2） | 1013.85/1.2 | **844.8750 m²** |
| m_solid（EC-F3） | (1+1)×1013.85×24×4 = 2×1013.85×96 | **194659.2 kg/d**（单池） |
| a_solid（EC-F4） | 194659.2/150 | **1297.728 m²** |
| a_tank（EC-F5） | max(844.8750, 1297.728) = 1297.728（**固体负荷主控**） | **1297.728 m²** |
| d_raw（EC-F6） | √(4×1297.728/π) = √1652.454 → 0.5 m 档向上取整 | D = **41.0 m** |
| a_act（EC-F7） | π×41²/4 = π×420.25 | **1320.254 m²** |
| q_act（EC-F8） | 1013.85/1320.254（带 0.6~1.5 内，合格） | **0.7679202 m³/(m²·h)** |

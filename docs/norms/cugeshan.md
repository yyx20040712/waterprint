## 手算算例（1~3 组典型工况）

> 输入源：市政 golden 案例 `core/tests/golden/golden_data/municipal_34760/`（Q=34,760 m³/d 级）。
> 流量口径（docs/golden-cases.md 口径陷阱①已拍板）：**只取 q_avg_daily 与 Kz，q_design 派生**——
> Q_avg_daily = 34,760.7 m³/d、Kz = 1.4（数值为旧系统 WaterFlow 默认基线）→
> Q_design = 34760.7/86400 × 1.4 = 0.40232 × 1.4 = **0.56325 m³/s**。
> 单元参数取旧系统市政案例文件（`resources/yyx.ddesign.json`）实际值：
> n=3、b=65 mm、α=75°、h=0.6 m、v=0.8 m/s、v₁=0.7 m/s、s=10 mm、bar_shape=0（矩形 β=2.42）。
> 全部期望值为 **AI 草算，待领域专家复核**。

### 算例 1：golden 派生口径（主算例，未来 test_compute.py 期望值来源）

| 量 | 手算过程摘要 | 期望值 |
|----|--------------|--------|
| q（CG-F1） | 0.56325/3 = 0.18775 m³/s | 0.18775 m³/s（187.75 L/s） |
| n_gap（CG-F2） | 0.18775×√(sin75°) = 0.18775×0.98282 = 0.18452；分母 0.065×0.6×0.8 = 0.0312；0.18452/0.0312 = 5.914 → ceil = 6 | **6 个** |
| B（CG-F3） | 0.010×5 + 0.065×6 + 0.2 = 0.05+0.39+0.2 = 0.64 → ceil(6.4)×0.1 | **0.7 m** |
| B₁（CG-F4） | 0.18775/(0.6×0.7) = 0.18775/0.42 = 0.44702 → ceil(4.47)×0.1 | **0.5 m** |
| v_checked（CG-F5） | 0.18452/(0.065×0.6×6) = 0.18452/0.234 = 0.7886 m/s（带 0.6~1.0 内，合格） | **0.789 m/s** |
| v₁_checked（CG-F6） | 0.18775/(0.6×0.5) = 0.18775/0.3 = 0.6258 m/s（带 0.4~0.9 内，合格） | **0.626 m/s** |
| ξ（CG-F7） | (10/65)^(4/3) = 0.15385^1.3333 = 0.08244；ξ = 2.42×0.08244 = 0.19949 | **0.1995** |
| h₁（CG-F8） | h₀ = 0.19949×0.7886²/(2×9.81)×sin75° = 0.19949×0.62183/19.62×0.96593 = 0.006107；h₁ = 3×0.006107 = 0.01832 m（≤0.3 合格） | **0.0183 m** |
| H（CG-F9） | 0.6+0.01832+0.3 = 0.91832 → ceil(9.183)×0.1 | **1.0 m** |
| L（CG-F10） | tan75°=3.73205；L₁=(0.7−0.5)/(2×3.73205)=0.02679；L₂=0.01340；(0.2+0.6)/3.73205=0.21438；L=0.02679+0.01340+1.0+0.5+0.21438=1.75457 → ceil(17.55)×0.1 | **1.8 m** |
| W（CG-F11） | 34760.7×0.02/1000 = 695.214/1000 | **0.6952 m³/d** |
| 清渣方式（CG-F12） | 0.6952 > 0.2 | **机械清渣** |
| 栅渣 DS（CG-F13） | 0.6952×(1−0.80)×1000 = 0.6952×200 | **139.0 kg/d**（P=0.80，VS=0.85） |

### 算例 2：旧系统 0.57 口径（对照算例，用于交叉解释）

Q_design = 0.57 m³/s（旧系统 WaterFlow 默认值，与派生关系 0.56325 不符——golden-cases.md 已判为双轨病灶）：q = 0.19 m³/s；
n_gap：0.19×0.98282/0.0312 = 5.985 → ceil = **6**（同算例 1）；
B、B₁、H、L 与算例 1 相同（0.7 / 0.5 / 1.0 / 1.8 m）；
v_checked = 0.19×0.98282/0.234 = **0.798 m/s**；v₁_checked = 0.19/0.3 = **0.633 m/s**；
h₁ = 3×0.19949×0.798²/19.62×0.96593 = **0.0188 m**；
W = 0.57×86400×0.02/(1.4×1000) = **0.7035 m³/d**（DS = 140.7 kg/d）。

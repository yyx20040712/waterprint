## 公式表（ST-F1~ST-F9，DSL 公式串供 FormulaSpec 直用）

> DSL 语法子集同市政表；π 以内联常量 3.14159265 出现；管径 0.025 m 档
> （DN25 步进——细管档）向上取整不入 DSL（离散化后的 d_pipe/d_grav
> 作为下游公式输入符号）；0.66666667 为 2/3 指数内联常量（曼宁 R^(2/3)）。

| formula_id | 表达式（受限 DSL） | 变量 | 系数列（factor.shusong.*） | 出处 |
|-----------|--------------------|------|---------------------------|------|
| ST-F1 | `q_h = q_wet / 24` | q_wet 输泥量 m³/d（hebing 出流实值） | — | 给水排水设计手册（污泥管道） |
| ST-F2 | `q_si = q_h / 3600` | 秒流量 m³/s | — | 同上 |
| ST-F3 | `d_raw = sqrt(4 * q_si / (3.14159265 * v_press))` | v_press 压力流设计流速 m/s（0.025 m 档向上取整得 d_pipe） | velocity_band.min/max | GB 50014-2021 §8（条号待核对） |
| ST-F4 | `v_act = 4 * q_si / (3.14159265 * d_pipe ** 2)` | 实际流速校核（带 1.0~2.0 内） | velocity_band.min/max | 同上 |
| ST-F5 | `i_req = (v_grav_min * n_manning / ((d_grav / 4) ** 0.66666667)) ** 2` | 重力流满流最小坡度需求（曼宁反解；d_grav 重力段管径 m） | gravity_v_min；n_manning | 给水排水设计手册（第 1 册）曼宁公式 |
| ST-F6 | `v_grav = (1 / n_manning) * ((d_grav / 4) ** 0.66666667) * sqrt(i_slope)` | i_slope 整定坡度（max(i_req, slope_min)——最小坡度条款控制） | n_manning；slope_min | 给水排水设计手册（第 5 册）输泥管坡度 |
| ST-F7 | `i_slope = max(i_req, slope_min)` | 整定坡度显式（DSL 白名单 max） | slope_min | 同上 |
| ST-F8 | `ds_out = ds_in` | **DS 穿流守恒**（输送不改泥质） | — | contracts.sludge R1（守恒不变量） |
| ST-F9 | `p_out = p_in` | 含水率穿流 | — | 同上 |

## 手算算例（主+副两组典型工况）

主算例输入：q_wet=409.3365833333 m³/d、v_press=1.5、d_grav=0.15、
n_manning=0.013、v_grav_min=0.7、slope_min=0.01。

| 量 | 手算过程摘要 | 期望值 |
|----|--------------|--------|
| q_h（ST-F1） | 409.3365833333/24 | **17.0556909722 m³/h** |
| q_si（ST-F2） | 17.0556909722/3600 | **0.0047376919 m³/s** |
| d_raw（ST-F3） | √(4×0.0047376919/(π×1.5)) | **0.063415123 m** |
| d_pipe（ST-F3 取整） | 0.025 m 档向上取整（0.0634→0.075） | **DN75（0.075 m）** |
| v_act（ST-F4） | 4×0.0047376919/(π×0.075²)（带 1.0~2.0 内，合格） | **1.0723940856 m/s** |
| i_req（ST-F5） | (0.7×0.013/(0.0375^0.66666667))²（DN150 满流） | **0.0065974246** |
| i_slope（ST-F7） | max(0.0065974246, 0.01)（最小坡度条款控制） | **0.01** |
| v_grav（ST-F6） | (1/0.013)×0.0375^0.66666667×√0.01（≥0.7 合格） | **0.8618085957 m/s** |
| ds_out/p_out（ST-F8~F9） | 穿流（DS 守恒） | **5306.515 kg/d / 0.9870363041（不变）** |

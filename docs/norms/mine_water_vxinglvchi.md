## 公式表（KV-F1~KV-F11，DSL 公式串供 FormulaSpec 直用）

| formula_id | 表达式（受限 DSL） | 变量 | 系数列（factor.mine_vxinglvchi.*） | 出处 |

| KV-F2 | `t_w = 24 - 24 * (t_bw / 60) / t_filter` | t_bw 单格反冲停滤历时 min（三阶段合计）；t_filter 过滤周期 h | cycle_band.min/max | 给水排水设计手册（有效过滤时长） |

## 水质衔接式（矿井水线水质链）

- 入流（gaomidu 表出流）：SS_in = **6.8 mg/L**、COD_in = **56.0 mg/L**
- 出流（衔接下游 ziwai 表）：SS_out = 6.8×(1−0.80) = **1.36 mg/L**；
  COD_out = 56×(1−0.075) = **51.8 mg/L**
- NH3N/TN/TP/TDS/pH 穿流不变；BOD5 全线不建键
- 出水校核注记：SS 1.36 mg/L 满足 GB/T 31392-2022 回用与 GB 20426-2006
  排放（SS ≤50 mg/L 档）；COD 51.8 mg/L **贴 GB 20426-2006 限值 50
  mg/L 上方**（键默认中值链的客观呈现——设计达标校核归 M3a2 实装批，
  cifenli/gaomidu 键值上调敏感性见追认点 12）
- **与市政同名构筑物边界差异**：市政 vxinglvchi（municipal/
  vxinglvchi.md，GB 50013-2018 §9.5 均质滤料 7~10 m/h）——本表低滤速
  4~6 m/h 精滤档、滤层 0.8~1.2 m（市政 1.2~1.5）、周期 24~48 h 同带但
  低浊进水工况、扫洗强度 2.0（市政 1.8）；出水目标（市政=紫外进水/
  一级 A；矿井水=回用+外排双目标）与规范依据（市政 GB 50013-2018；
  矿井水 GB/T 41019-2021+GB/T 31392-2022）不同——键空间经 mine_
  限定物理隔离（§14.3）。

## 手算算例（2 组典型工况）

主算例输入：Q_avg_daily = 43836.0、n = 16、v_filter = 5.0、k_self =
1.05、t_filter = 24 h、t_bw = 12 min、ratio_lb = 2.0、h_media = 1.0、
h_water = 1.2、h_super = 0.5、h_plate = 0.1、h_under = 0.9、
q_w_sim = 3、q_w = 5、q_sweep = 2、t_sim = 4、t_water = 5、wall_coef = 0.35。

| 量 | 手算过程摘要 | 期望值 |
|----|--------------|--------|
| q_d（KV-F1） | 43836×1.05 | **46027.8 m³/d** |
| t_w（KV-F2） | 24−24×(12/60)/24 | **23.8 h** |
| f_total（KV-F3） | 46027.8/(5×23.8) | **386.7882352941 m²** |
| f_single（KV-F4） | 386.7882352941/16 | **24.1742647059 m²** |
| v_force_act（KV-F5） | 16/15×5（≤10 合格） | **5.3333333333 m/h** |
| B（KV-F6） | √(24.1742647059/2)=3.477… → 0.1 m 档 | **3.5 m** |
| L（KV-F7） | 24.1742647059/3.5=6.907… → 0.1 m 档 | **7.0 m** |
| w_wash（KV-F8） | (3×4+5×5+2×12)×60/1000 | **3.66 m³/(格·次)** |
| eta_wash（KV-F9） | 3.66×(24/24)/(46027.8/16)（≤5% 合格） | **0.0012722746（0.13%）** |
| h_total（KV-F10） | 0.5+1.2+1.0+0.1+0.9 | **3.7 m** |
| v_concrete（KV-F11） | 7.0×3.5×3.7×16×0.35 | **507.64 m³**（概算） |

副算例（少格数）：n = 12（其余同主算例）：f_single =
**32.2323529412 m²**；v_force_act = **5.4545454545 m/h**（≤10 合格）；
B = **4.1 m**；L = **7.9 m**；eta_wash = **0.0009542059（0.10%）**；
v_concrete = **503.3406 m³**。

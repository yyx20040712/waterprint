## 手算算例（主+副两组典型工况——带式主线/离心副档）

主算例输入（**带式压滤档**）：ds_in=3378.92342625 kg/d、
q_wet=117.9996474262 m³/d、p_in=0.9713649702（xiaohua 主算例出流）；
dose_pam=4、q_machine=20（带式）、eta_capture=0.95、p_cake=0.78、
n_standby=1。

| 量 | 手算过程摘要 | 期望值 |
|----|--------------|--------|
| w_pam（TU-F1） | 3378.92342625×4/1000 | **13.515693705 kg/d** |
| q_in_h（TU-F2） | 117.9996474262/24 | **4.9166519761 m³/h** |
| n_machine_raw（TU-F3） | 4.9166519761/20 = 0.2458 → 整台向上取整 | n_machine_duty = **1 台（带式）** |
| n_machine_total（TU-F4） | 1+1 | **2 台（1 用 1 备）** |
| ds_cake（TU-F5） | 3378.92342625×0.95（DS 守恒·回收） | **3209.9772549375 kg/d** |
| q_cake（TU-F6） | 3209.9772549375/((1−0.78)×1000)（泥饼三量链） | **14.5908057043 m³/d** |
| q_filtrate（TU-F7） | 117.9996474262−14.5908057043（滤液——回流口默认关） | **103.408841722 m³/d** |
| ds_filtrate（TU-F8） | 3378.92342625−3209.9772549375（DS 守恒闭合） | **168.9461713125 kg/d** |

浮点末位注记（TU-F7 主算例，M3b1 二审 M1 回填——照 KT-F10 π 注记
先例，数值零变更）：q_filtrate 期望列 103.408841722 系 12 位显示
舍入——实装链式求值（入流往返 117.99964742624991 − q_cake 实算
14.590805704261367）得 103.40884172198854，差 <1.2e-12，断言容差
1e-9 覆盖。本注记不改任何期望值。

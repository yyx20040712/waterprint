## 手算算例（1~3 组典型工况）

> 输入源与流量口径同 `docs/norms/cugeshan.md`：Q_design(派生) = 0.56325 m³/s、Q_avg_daily = 34760.7 m³/d、Kz = 1.4。
> 单元参数取旧系统市政案例文件（`resources/yyx.ddesign.json`）实际值：
> n=2、q_surf=150 m³/(m²·h)、t=30 s、h₁=0.3 m、X=30、T_clean=2 d、θ=55°、d_r=0.5 m、B渠=0.8 m、v渠=1.0 m/s。
> 全部期望值为 **AI 草算，待领域专家复核**。

### 算例 1：golden 派生口径（主算例，未来 test_compute.py 期望值来源）

| 量 | 手算过程摘要 | 期望值 |
|----|--------------|--------|
| Q₁（CS-F1） | 0.56325/2 = 0.28163 m³/s；Q₁h = 0.28163×3600 = 1013.85 m³/h | 0.28163 m³/s；1013.85 m³/h |
| D（CS-F2） | √(4×1013.85/(π×150)) = √(4055.42/471.24) = √8.6058 = 2.9336 → ceil(29.34)×0.1 | **3.0 m** |
| h₂（CS-F3） | 150×30/3600 = 4500/3600 = 1.25 m（带 1.0~2.0 内，合格） | **1.25 m** |
| 径深比（CS-F4） | 3.0/1.25 = 2.40（带 2.0~2.5 内，合格） | **2.40** |
| V_eff（CS-F5） | π×(1.5)²×1.25 = π×2.25×1.25 = π×2.8125 | **8.836 m³** |
| t_actual（CS-F6） | 8.8357/0.28163 = 31.37 s（带 25~60 内，合格） | **31.4 s** |
| V_sand（CS-F7） | (34760.7/2)×30/10⁶ = 17380.35×30/10⁶ = 521410.5/10⁶（单池） | **0.5214 m³/d** |
| V_hopper（CS-F8） | 0.5214×2×1.5 | **1.5642 m³** |
| d_upper（CS-F9） | 0.5×3.0 | **1.5 m** |
| h₄（CS-F10） | (1.5−0.5)/(2×tan55°) = 1.0/(2×1.42815) = 1.0/2.85630 | **0.3501 m** |
| V_cone（CS-F11） | π×0.3501/3×(0.75²+0.75×0.25+0.25²) = π×0.3501/3×(0.5625+0.1875+0.0625) = 1.09996/3×0.8125 = 0.36665×0.8125 | **0.2979 m³** |
| h_cyl（CS-F12） | A_upper = π×0.75² = 1.76715；(1.5642−0.2979)/1.76715 = 1.2663/1.76715 = 0.7166 → ceil(7.17)×0.1 | **0.8 m** |
| V_storage | V_cyl = 1.76715×0.8 = 1.4137；合计 0.2979+1.4137 | **1.7116 m³**（> V_hopper，合格） |

| L直（CS-F15） | max(7×0.8, 4.5) = max(5.6, 4.5) | **5.6 m** |
| B出（CS-F16） | 2×0.8 | **1.6 m** |
| 沉砂污泥口（CS-F17） | DS单池 = 0.5214×0.4×1600 = 0.5214×640 = 333.7 kg/d；全厂 Q_wet = 0.5214×2 = 1.0428 m³/d、DS = 667.4 kg/d | **Q_wet 1.0428 m³/d；DS 667.4 kg/d**（P=0.60，VS=0.05） |

### 算例 2：旧系统 0.57 口径（对照算例）

Q_design = 0.57 m³/s：Q₁ = 0.285 m³/s，Q₁h = 1026 m³/h；
D：√(4×1026/471.24) = √8.7090 = 2.9511 → ceil(29.51)×0.1 = **3.0 m**（同算例 1）；
h₂、径深比、V_eff、V_sand、V_hopper、d_upper、h₄、V_cone、h_cyl、V_storage、H、L直、B出 与算例 1 完全相同（不依赖 Q_design 或被取整吸收；V_sand 用 Q_avg_daily）；
t_actual = 8.8357/0.285 = **31.0 s**；
A渠 = **0.285 m²**；h渠 = 0.285/0.8 = **0.356 m**（宽深比 0.8/0.356 = **2.25**）。

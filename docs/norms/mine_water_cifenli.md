## 公式表（KS-F1~KS-F8，DSL 公式串供 FormulaSpec 直用）

> DSL 语法子集同市政表；π 以内联常量 3.14159265 出现；盘片数整台 ceil
> 不入 DSL——离散化后的值作为下游公式输入符号。

| formula_id | 表达式（受限 DSL） | 变量 | 系数列（factor.mine_cifenli.*） | 出处 |
|-----------|--------------------|------|--------------------------------|------|
| KS-F1 | `q_1h = q_design_h / n_units` | n_units 台数（声明面离散档） | — | GB/T 41019-2021（条号待核对） |
| KS-F2 | `a_disk = 2 * 3.14159265 * d_disk ** 2 / 4 * eta_im` | d_disk 盘径 m；eta_im 浸没比（单盘双面有效面积） | disk.diameter、disk.immersion | GB/T 41019-2021（磁加载分离，条号待核对） |
| KS-F3 | `a_total_req = q_1h / q_surf` | q_surf 盘面表面负荷 m³/(m²·h)（主控参数） | surface_load_band.min/max | GB/T 41019-2021（条号待核对） |
| KS-F4 | `n_disks = a_total_req / a_disk` | 盘片数（向上取整） | — | 同上 |
| KS-F5 | `v_line = 3.14159265 * d_disk * omega / 60` | omega 转速 rpm（盘缘线速度 ≤0.3 校核） | disk.speed_max | GB/T 41019-2021（条号待核对）；给水排水设计手册（机械分离） |
| KS-F6 | `w_ss = q_avg_daily * ss_in * eta_ss / 1000000` | ss_in 进水 SS mg/L（衔接链值）；eta_ss 截留率（w_ss t/d 干基） | removal.mine_cifenli.ss | 给水排水设计手册（泥量衡算） |
| KS-F7 | `q_sludge = w_ss * 1000 / ((1 - p_sludge) * rho_sludge)` | p_sludge 磁泥含水率；rho_sludge 密度 kg/m³ | sludge.moisture、sludge.density | 给水排水设计手册（污泥量） |

## 水质衔接式（矿井水线水质链）

- 入流（ningjiao 表出流）：SS_in = **680.0 mg/L**、COD_in = **200.0 mg/L**
- 出流：SS_out = 680×(1−0.90) = **68.0 mg/L**；COD_out = 200×(1−0.60)
  = **80.0 mg/L**（衔接下游 gaomidu 表）
- NH3N/TN/TP/TDS/pH 穿流不变；BOD5 全线不建键
- 磁种衡算注记：投加 21.918 t/d（ningjiao 表）、回收 95% → 循环量
  20.8221 t/d、**净耗 1.0959 t/d**（随磁泥流失，磁泥含磁种回用经济性
  归 M3 验收批核算）

## 手算算例（2 组典型工况）

主算例输入：Q_design_h = 2739.75、n_units = 4、d_disk = 1.5、eta_im =
0.35、omega = 3 rpm、q_surf = 25、ss_in = 680.0、eta_ss = 0.90、
p_sludge = 0.92、rho_sludge = 1100、m_seed = 21918.0 kg/d、eta_recover = 0.95。

| 量 | 手算过程摘要 | 期望值 |
|----|--------------|--------|
| q_1h（KS-F1） | 2739.75/4 | **684.9375 m³/h** |
| a_disk（KS-F2） | 2×3.14159265×1.5²/4×0.35（单盘双面有效） | **1.2370021059 m²** |
| a_total_req（KS-F3） | 684.9375/25（带 20~40 内，合格） | **27.3975 m²** |
| n_disks（KS-F4） | 27.3975/1.2370021059=22.148… 向上取整 | **23 盘/台** |
| v_line（KS-F5） | 3.14159265×1.5×3/60（≤0.3 合格） | **0.2356194488 m/s** |
| w_ss（KS-F6） | 43836×680×0.90/10⁶ | **26.827632 t/d**（干基） |
| q_sludge（KS-F7） | 26.827632×1000/((1−0.92)×1100) | **304.8594545455 m³/d**（磁泥湿量全厂） |

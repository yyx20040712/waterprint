## 公式表（ZW-F1~ZW-F13，DSL 公式串供 FormulaSpec 直用）

> DSL 语法子集：`OUT = RHS`，算术 + 白名单函数 {min,max,abs,sqrt,log10}；
> 取整不入 DSL——离散化后的值（h_w、n_lamp、n_module）作为下游公式
> 输入符号；×3600 形态为小时-秒换算条文常量。

| formula_id | 表达式（受限 DSL） | 变量 | 系数列（factor.ziwai.*） | 出处 |
|-----------|--------------------|------|---------------------------|------|
| ZW-F1 | `q_c = q_design / n_channel` | n_channel 渠道数（2 条并联同时运行各半过流+超越/模块切换备用——单渠事故工况 0.78 m/s 超 velocity_band.max=0.6 注记，构造） | — | 给水排水设计手册（明渠紫外布置） |
| ZW-F2 | `h_w_raw = q_c / (v_channel * b_c)` | v_channel 渠内流速 m/s；b_c 渠宽 m（构造）（h_w_raw 按 0.1 m 档向上取整得 h_w） | velocity_band.min/max | 给水排水设计手册（渠道流速常用带） |
| ZW-F3 | `v_channel_act = q_c / (b_c * h_w)` | 实际流速校核 | velocity_band.min/max | 同上 |
| ZW-F4 | `n_lamp_raw = q_design_h / q_per_lamp / f_aging` | q_per_lamp 单灯处理量 m³/h（T254=60%、剂量 30 mJ/cm² 档新灯概算）；f_aging 灯管老化系数（n_lamp 按整支向上取整） | q_per_lamp；f_aging | 给水排水设计手册（灯管概算法） |
| ZW-F5 | `n_module_raw = n_lamp / n_lamp_module` | n_lamp_module 每模块灯管数（构造，n_module 向上取整） | — | 给水排水设计手册（模块化布置） |
| ZW-F6 | `n_module_series = n_module / n_channel` | 每渠串列模块数 | — | 同上 |
| ZW-F7 | `l_lamp_zone = n_module_series * l_module` | l_module 模块长 m（构造） | — | 同上 |
| ZW-F8 | `l_channel = 2 * l_stab + l_lamp_zone` | l_stab 进/出水稳流段长 m（构造） | — | 给水排水设计手册 |
| ZW-F9 | `t_exp = b_c * h_w * l_lamp_zone / q_c` | 有效接触（曝光）时间校核 s | t_exp_band.min/max | 给水排水设计手册（剂量=强度×时间） |
| ZW-F10 | `c_fecal_out = c_fecal_in / 10 ** n_log` | c_fecal_in 进水粪大肠个/L（设计假定）；n_log log 去除对数级 | fecal.c_in_design；fecal.log_removal | GB 50014-2021 消毒章节；给水排水设计手册 |
| ZW-F11 | `h_submerge = h_w - h_module` | h_module 模块高 m（构造）；h_submerge ≥0 淹没校核 | — | 给水排水设计手册（灯管全淹没） |
| ZW-F12 | `h_channel = h_super + h_w` | h_super 渠超高 m | superheight | GB 50014-2021 §6（超高一般要求） |
| ZW-F13 | `v_concrete = l_channel * b_c * h_channel * n_channel * wall_coef` | 概算口径混凝土量 | wall_thickness_coef | 给水排水设计手册（概算口径） |

其他数据键：factor.ziwai.elevation_loss（高程链经验水损）；
去除率键 removal.ziwai.{bod5,cod,ss}.mod_default（**物理消毒无去除，
显式 0.0**，见衔接式）。设计剂量 D=30 mJ/cm² 与穿透率 T254 档为
选型参数（dose/t254_band），剂量校核语义 = 选型剂量 ≥ 设计剂量
（ZW-F4 概算链承载）。

## 手算主算例（golden 全厂口径，未来 test_compute.py 期望值来源）

输入：Q_design = 0.56325 m³/s（q_design_h = 2027.70 m³/h）、
n_channel = 2、v_channel = 0.4 m/s、b_c = 1.2 m、q_per_lamp = 40
m³/h、f_aging = 0.8、n_lamp_module = 8、l_module = 0.6 m、
l_stab = 1.2 m、h_module = 0.5 m、h_super = 0.5 m、c_fecal_in =
1×10⁵ 个/L、n_log = 4、wall_coef = 0.35。

| 量 | 手算过程摘要 | 期望值 |
|----|--------------|--------|
| q_c（ZW-F1） | 0.56325/2 | **0.281625 m³/s** |
| h_w_raw（ZW-F2） | 0.281625/(0.4×1.2) → 0.1 m 档向上取整 | h_w = **0.6 m** |
| v_channel_act（ZW-F3） | 0.281625/(1.2×0.6)（带 0.3~0.6 内，合格） | **0.3911458 m/s** |
| n_lamp_raw（ZW-F4） | 2027.70/40/0.8 = 50.6925/0.8 → 整支向上取整 | n_lamp = **64 支** |
| n_module（ZW-F5） | 64/8 | **8 模块** |
| n_module_series（ZW-F6） | 8/2 | **4 模块/渠** |
| l_lamp_zone（ZW-F7） | 4×0.6 | **2.4 m** |
| l_channel（ZW-F8） | 2×1.2+2.4 | **4.8 m** |
| t_exp（ZW-F9） | 1.2×0.6×2.4/0.281625（带 5~10 内，合格） | **6.135819 s** |
| c_fecal_out（ZW-F10） | 100000/10⁴（≤1000 标准值，合格） | **10 个/L** |
| h_submerge（ZW-F11） | 0.6−0.5（≥0 灯管全淹没，裕量偏紧注记） | **0.1 m** |
| h_channel（ZW-F12） | 0.5+0.6 | **1.1 m** |
| v_concrete（ZW-F13） | 4.8×1.2×1.1×2×0.35 | **4.4352 m³**（概算口径） |

剂量档选型注记：设计剂量 30 mJ/cm²（深度处理出水档 24~40 中值）；
q_per_lamp=40 系新灯、T254=60% 档概算锚点，f_aging=0.8 修正至寿命
末期——穿透率取下限 55% 时应下调 q_per_lamp 或增加灯管（选型以
设备剂量验证数据为准，追认点）。渠道备用语义+t_exp 未计短流折减
（×0.8≈4.9 s 贴近带下限 5 s，剂量主线由 ZW-F4 概算锚承载）。

# 规范摘录与手算对照（docs/norms）

> 公式语义依据 = **规范条文**；旧实现仅作交叉对照（§5）。
> 本目录是"测试只能证明代码符合写下的规格"这一盲区（§16 A9）的唯一防线：
> **每个工艺单元交付时，必须有条文摘录 + 手算对照表，由领域专家签字。**

## 流程（每单元四件套的文档半）

1. 实现者摘录该单元涉及的全部条文（规范号 + 条文号 + 原文关键句）；
2. 按条文手算 1~3 组典型算例（golden 数值来源）；
3. 与旧系统结果交叉对照，差异逐条解释（口径不同/旧错）；
4. 领域专家复核签字（本表签字栏）→ 测试期望值锁定（只读）。

## 文件清单（M0.5 已目录化；单元对照表随交付创建，命名 = 单元 ID）


## 涉及规范清单（实现期逐步摘录）

- 方法主线与单元默认值以 ADR-008/ADR-009 拍板为准——摘录条文时须与
  已拍板路线一致（如 AAO 摘 §7.6.10 负荷法主公式，泥龄条文作校核侧）。
- GB 50014-2021 室外排水设计标准（水线主依据）
- GB 50013-2018 室外给水设计标准（V 滤构造/高密同型池参数）
- HJ 576-2010（AAO）/ HJ 577-2010（SBR/CASS）工程技术规范
- GB/T 50001 房屋建筑制图统一标准（出图基线，ADR-006）
- CJ/T 3008.3-1993 巴歇尔水槽 / CJJ 131-2009 污泥处理技术规程 /
  T/CECS 636-2019 磁介质混凝沉淀（厂商技术类单元的依据）
- 矿井水线：GB/T 19223-2015、GB/T 31392-2022、GB/T 41019-2021、
  GB 20426-2006（ADR-009 附注的标准版本事实为准）
- 各单元专用规范/手册（给水排水设计手册第 5 册、Metcalf 仅参照——
  层级见 ADR-009 B16）——摘录时登记规范号与年份；
  **禁止无出处公式进注册表**（formulas R2）。

## 硬规则

- 手算对照表是单元测试 golden 期望值的唯一合法来源——
  实现者自编数字 = 评审拒绝；
- 条文摘录引用精确到条（§x.x.x），复核签字不可免。

## 公式表（TS-F1~TS-F14，DSL 公式串供 FormulaSpec 直用）

> DSL 语法子集：`OUT = RHS`，算术 + 白名单函数 {min,max,abs,sqrt,log10}；
> 取整（ceil）不入 DSL——离散化后的值（n_pump_duty、d_pipe）作为下游
> 公式输入符号；π 以内联常量 3.14159265 出现；60/900 为分-秒/启停周期
> 条文常量；×3600/÷3600 为时-秒换算（q_design_h/q_pump_si 由 compute
> 符号合成）。比阻 a_pipe 按选定的 DN 档从舍维列夫比阻表键取值
> （DN 档 d_pipe×1000 命中表键，越表拒）。

| formula_id | 表达式（受限 DSL） | 变量 | 系数列（factor.wushui_tisheng.*） | 出处 |
|-----------|--------------------|------|-----------------------------------|------|
| TS-F1 | `n_pump_raw = q_design_h / q_per_pump` | q_per_pump 单泵流量概算锚 m³/h（n_pump_duty 按整台向上取整） | pump.q_per_unit | 给水排水设计手册（泵站选型常用档） |
| TS-F2 | `q_pump = q_design_h / n_pump_duty` | 单泵流量 m³/h（工作泵均分） | pump.q_flow_band.min/max | 同上 |
| TS-F3 | `n_pump_total = n_pump_duty + n_standby` | n_standby 备用泵台数（2 用 1 备口径同 tiaojiechi 表 TJ-F10 注记） | — | GB 50014-2021 §6.1（备用泵一般要求） |
| TS-F4 | `d_pipe_raw = sqrt(4 * q_pump_si / (3.14159265 * v_pipe))` | v_pipe 出水管名义流速 m/s（d_pipe 按 0.1 m 档=DN 档向上取整） | — | 给水排水设计手册（压力管经济流速） |

## 手算主算例（golden 全厂口径，未来 test_compute.py 期望值来源）

输入：Q_design = 0.56325 m³/s（q_design_h = 2027.70 m³/h）、
q_per_pump = 1100 m³/h、n_standby = 1、h_static = 10.0 m、h_free =
1.5 m、v_pipe = 1.2 m/s、l_pipe = 100 m、ζ_total = 5、t_well = 10 min、
h_well = 2.0 m、h_super = 0.5 m、wall_coef = 0.35。

| 量 | 手算过程摘要 | 期望值 |
|----|--------------|--------|
| n_pump_raw（TS-F1） | 2027.70/1100 = 1.8434 → 整台向上取整 | n_pump_duty = **2 台（工作）** |
| q_pump（TS-F2） | 2027.70/2（带 400~1500 内，合格） | **1013.85 m³/h**（0.281625 m³/s） |
| n_pump_total（TS-F3） | 2+1 | **3 台（2 用 1 备）** |
| d_pipe（TS-F4） | √(4×0.281626/(π×1.2)) = 0.546639 → 0.1 m 档=DN 档向上取整 | **DN600（0.6 m）** |
| v_pipe_act（TS-F5） | 4×0.281626/(π×0.6²)（带 0.7~1.5 内，合格） | **0.996048 m/s** |
| h_friction（TS-F6） | 0.02602×100×0.281626²（DN600 档比阻） | **0.206373 m** |
| h_local（TS-F7） | 5×0.996048²/(2×9.81) | **0.252832 m** |
| h_loss（TS-F8） | 0.206373+0.252832 | **0.459205 m** |
| h_pump（TS-F9） | 10.0+0.459205+1.5（扬程三分量） | **11.959205 m** |
| v_well（TS-F10） | 0.281626×60×10（带 5~15 min 对应容积，合格） | **168.9756 m³** |
| a_well（TS-F11） | 168.9756/2.0 | **84.4878 m²** |
| n_start（TS-F12） | 900×0.281626/168.9756（≤6 次/h，合格） | **1.500000 次/h** |
| h_well_total（TS-F13） | 0.5+2.0 | **2.5 m** |
| v_concrete（TS-F14） | 84.4878×2.5×0.35 | **73.9268 m³**（概算口径） |

容差注记：手算按 5 位舍入 Q_design = 0.56325（q_design_h = 2027.70），
引擎用精确 34760.7/86400×1.4 = 0.5632520833（q_design_h = 2027.7075）
——差 <8e-3 m³/h，泵流量/水损/扬程面 1e-3~1e-4 容差覆盖；离散化项
（n_pump_duty = 2/DN600）不受扰；v_well/n_start 按引擎精确值
（168.9756/1.500000）断言。

## 追认点（本表工程裁量，领域专家批量追认清单）

1. **泵扬程三分量口径**（M2b1 追认点 14 承接）：h_pump = 静扬程 +
   管路损失 + 自由水头；静扬程 10.0 m 为工程常用假定（实际由泵站
   前后水位高程定——elevation 面输入，归 UF-32 契约对接）。
2. **单泵流量概算锚**：q_per_pump = 1100 m³/h 决定工作泵台数 ceil
   （主算例恰落 2 用 1 备档）；锚值与实际选泵型号（设备采购面）的
   匹配归追认/设备批。
3. **比阻 v<1.2 m/s 修正未计**：主算例 v_pipe_act = 0.996 < 1.2，
   舍维列夫低流速档 h_friction 应乘修正（~1.11）——对 h_pump 影响
   <0.03 m（0.3%），保守性裁定归追认。
4. **DN 档表覆盖面**：比阻键仅录 DN300~DN800（泵站常用档）；越表
   DN 显式拒——扩档（DN900+）待需要时增补数据包键。
5. **集水井容积基准**：按最大一台泵出水量×t_well（工作泵均分口径）；
   手册另有"不小于最大一台泵 5 min 出水量"下限式——两口径在均分
   泵组下同义，非均分泵组（大小泵搭配）口径归追认。
6. **elevation_loss 语义**：泵房为提升单元（能量增加非损失），本键
   承载站内过流构件（格栅/流道）水损 0.3 m；提升能量由 h_pump 公式
   承载——两键语义分工与 elevation 面对接归 UF-32 契约核对。
7. **900 启停常数**：n_start = 900q/V 按最不利入流（= 半泵流量）推导
   的周期公式（3600/4）；按实际入流过程线的启停次数校核归运行面。

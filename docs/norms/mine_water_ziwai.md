## 公式表（KZ-F1~KZ-F11，DSL 公式串供 FormulaSpec 直用）

> DSL 语法子集同市政表；g=9.81 m/s²（物理条文常量内联）。

| formula_id | 表达式（受限 DSL） | 变量 | 系数列（factor.mine_ziwai.*） | 出处 |
|-----------|--------------------|------|------------------------------|------|
| KZ-F1 | `q_ch = q_design * 3600 / n` | n 渠数（声明面离散档，检修兼顾 ≥2） | — | GB/T 41019-2021（条号待核对） |
| KZ-F2 | `a_ch = b_channel * h_channel` | b_channel 渠宽 m；h_channel 渠内有效水深 m（构造默认 1.7/1.2） | — | 给水排水设计手册（消毒渠） |
| KZ-F3 | `v_ch = (q_ch / 3600) / a_ch` | 渠内流速校核（带 velocity_band 内） | velocity_band.min/max | 给水排水设计手册（渠内流速） |
| KZ-F4 | `t_eff = (t254 / 100) ** n_t` | t254 穿透率 %；n_t 透光指数（构造默认 1.5） | t254_band.min/max | 给水排水设计手册（紫外穿透） |
| KZ-F5 | `i_avg = p_lamp * n_layer * eta_geo * t_eff * f_aging * f_fouling / (10 * a_ch)` | p_lamp 单灯功率 W；n_layer 每排灯数；eta_geo 几何效率；f_aging 老化系数；f_fouling 结垢系数（i_avg W/m²→折 mW/cm² 量纲链） | f_aging、f_fouling、eta_geo | 给水排水设计手册（灯管布置）；GB/T 41019-2021（结垢衰减，条号待核对） |
| KZ-F6 | `dose_row = i_avg * d_long / v_ch` | d_long 排间距 m（构造默认 0.12，d_long/v=单排曝光时间） | — | 给水排水设计手册（剂量=强度×时间） |
| KZ-F7 | `n_rows = dose / dose_row` | dose 设计剂量 mJ/cm²（排数向上取整） | dose | GB/T 31392-2022（条号待核对） |
| KZ-F8 | `dose_act = n_rows * dose_row` | 实算剂量校核（≥ dose 合格） | dose | 同上 |
| KZ-F9 | `t_contact = n_rows * d_long / v_ch` | 有效接触时间 | — | 给水排水设计手册 |
| KZ-F10 | `h_loss = max(xi_total * v_ch ** 2 / (2 * 9.81), loss_min)` | xi_total 渠内局部损失系数和（构造默认 3）；loss_min 构造裕量下限 | loss_min | 给水排水设计手册（渠道水损） |
| KZ-F11 | `h_total = h_super + h_channel` | h_super 超高 | superheight | 给水排水设计手册 |

## 手算算例（2 组典型工况）

主算例输入：Q_design_h = 2739.75、n = 3、b_channel = 1.7、h_channel =
1.2、t254 = 65、n_t = 1.5、p_lamp = 250、n_layer = 6、eta_geo = 0.7、
f_aging = 0.7、f_fouling = 0.8、d_long = 0.12、xi_total = 3、dose = 30、
h_super = 0.3。

| 量 | 手算过程摘要 | 期望值 |
|----|--------------|--------|
| q_ch（KZ-F1） | 2739.75/3 | **913.25 m³/h** |
| a_ch（KZ-F2） | 1.7×1.2 | **2.04 m²** |
| v_ch（KZ-F3） | (913.25/3600)/2.04（带 0.05~0.7 内，合格） | **0.1243532135 m/s** |
| t_eff（KZ-F4） | 0.65^1.5 | **0.5240467536** |
| i_avg（KZ-F5） | 250×6×0.7×0.5240467536×0.7×0.8/(10×2.04) | **15.1048770167** |
| dose_row（KZ-F6） | 15.1048770167×0.12/0.1243532135 | **14.576102948 mJ/cm²** |
| n_rows（KZ-F7） | 30/14.576102948=2.058… 向上取整 | **3 排** |
| dose_act（KZ-F8） | 3×14.576102948（≥30 合格） | **43.728308844 mJ/cm²** |
| t_contact（KZ-F9） | 3×0.12/0.1243532135 | **2.8949794689 s** |
| h_loss（KZ-F10） | max(3×0.1243532135²/19.62, 0.10) | **0.1 m** |
| h_total（KZ-F11） | 0.3+1.2 | **1.5 m** |

副算例（单渠检修工况）：n = 1（其余同主算例）：q_ch = **2739.75 m³/h**；
v_ch = **0.3730596405 m/s**（带内）；dose_row = **4.8587009827 mJ/cm²**
（流速升高单排剂量降）；n_rows = **7 排**；dose_act =
**34.0109068786 mJ/cm²**（≥30 合格）；t_contact = **2.2516506981 s**。
注记：n=1 为检修极限工况（失去备用）——运行面低流量时流速贴带下限
（0.05 m/s）可接受、以剂量达标为准（旧系统 warning 同口径）。

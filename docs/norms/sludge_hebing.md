## 单元信息

- UNIT_ID：sludge_hebing（新系统身份 sludge/hebing；系数键=裸短名
  factor.hebing.*，sludge 线投影口径——app._unit_params 剥 `sludge_` 前缀）
- 中文名 / 业务线：污泥合并（各线排泥汇流+全厂污泥产量衡算节点）/ 污泥处理
- 结构组成：多股污泥汇流（初沉污泥/剩余污泥/化学污泥三股主线入口）+
  汇流井（构造概算归 bengzhan 集泥井面，本表不建井容公式）
- 工艺位置：各线单元排泥口 → **hebing 污泥合并** → shusong 污泥输送
  （SLUDGE 端口独立通道，contracts.sludge.mix 为守恒正门）
- 规范依据（主）：GB 50014-2021 §8.1（污泥量计算——**§8.1.4 表 5 污泥
  产率 y**（ADR-008 ④ 拍板口径；条号随追认核对），其余小节条号待核对）；
  《给水排水设计手册（第 5 册 城镇排水）》污泥处理章（污泥量衡算/含水率
  换算常用值）；叙述性依据（数值 source 不标）：CJJ 131-2009
- 旧系统对应 mod（仅交叉对照）：wuni_hebing（mod v5.1.0）
- 流量口径：按**平均日泥量**（污泥链无时变化系数概念——日计量口径）；
  主算例三股输入=市政 34760 案例实值（ds 3240.12/1928.690/137.7050 kg/d，
  含水率 0.96/0.994/0.98）

## 公式表（HB-F1~HB-F13，DSL 公式串供 FormulaSpec 直用）

> DSL 语法子集同市政表：`OUT = RHS`，算术 + 白名单函数
> {min,max,abs,sqrt,log10}；1000 为 kg/t·mg/L 换算常量。汇流三式
> （HB-F6/HB-F7）与 contracts.sludge.mix（P4 干基质量恒等）逐字镜像；
> 单位换算（工程口径 m³/d、kg/d ↔ 契约口径 m³/s、kg/s）归 M3b2 实装面。

| formula_id | 表达式（受限 DSL） | 变量 | 系数列（factor.hebing.*） | 出处 |
|-----------|--------------------|------|---------------------------|------|
| HB-F1 | `q_primary = ds_primary / ((1 - p_primary) * 1000)` | ds_primary 初沉股干泥 kg/d；p_primary 初沉污泥含水率 | — | 给水排水设计手册（污泥量换算） |
| HB-F2 | `q_bio = ds_bio / ((1 - p_bio) * 1000)` | ds_bio 剩余污泥股 kg/d；p_bio 剩余污泥含水率 | — | 同上 |
| HB-F3 | `q_chem = ds_chem / ((1 - p_chem) * 1000)` | ds_chem 化学污泥股 kg/d；p_chem 化学污泥含水率 | — | 同上 |
| HB-F4 | `ds_total = ds_primary + ds_bio + ds_chem` | **DS 守恒（汇流Σds）** | — | contracts.sludge.mix R1 镜像 |
| HB-F5 | `q_total = q_primary + q_bio + q_chem` | 湿量加和（Σq_wet） | — | 同上 |
| HB-F6 | `w_water = ds_primary * p_primary / (1 - p_primary) + ds_bio * p_bio / (1 - p_bio) + ds_chem * p_chem / (1 - p_chem)` | 干基水质量恒等（kg/d） | — | contracts.sludge.mix P4 镜像 |
| HB-F7 | `p_merged = w_water / (w_water + ds_total)` | 合并含水率反解（非简单平均） | — | 同上 |
| HB-F8 | `s_y = q_avg_daily * (s0_bod - se_bod) * y_yield / 1000` | **经验产率法主线**（ADR-008 ④）：q_avg_daily 平均日流量 m³/d；s0/se 生物池进出水 BOD5 mg/L | yield.y；yield.y_band.min/max | GB 50014-2021 §8.1.4 表 5 |
| HB-F9 | `k_dt = k_d20 * theta_kd ** (t_design - 20)` | Kd 温度修正；t_design 设计水温 ℃（参数） | k_decay20；theta_kd | 给水排水设计手册（动力学系数修正） |
| HB-F10 | `dx_bio = y_syn * q_avg_daily * (s0_bod - se_bod) / 1000 - k_dt * v_bio * x_vss / 1000` | **机理互校 ΔX=Y·QΔS−Kd·V·Xv**（ADR-008 ④）：v_bio 生物池容积 m³；x_vss MLVSS mg/L（衔接 aao 表） | yield_syn；yield_syn_band.min/max | 给水排水设计手册（活性污泥法产率） |
| HB-F11 | `dev_pct = abs(s_y - dx_bio) / s_y * 100` | 互校偏差 %（>dev_band.max 出警告——提示核对 SS/BOD 比） | dev_band.max | ADR-008 ④（已拍板口径） |
| HB-F12 | `ds_check = ds_primary + s_y + ds_chem` | 产率法口径全厂干泥量（初沉+产率法剩余+化学） | — | GB 50014-2021 §8.1（污泥量组成） |
| HB-F13 | `dev_close = abs(ds_total - ds_check) / ds_total * 100` | 汇流-产率法闭合差 % 校核 | — | 同上 |

其他数据键：factor.hebing.elevation_loss（汇流井/三通水损经验值）。

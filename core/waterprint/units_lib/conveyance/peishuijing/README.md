# conveyance_peishuijing —— 配水井（集配水线，M3）

向并联处理系列均匀分配水量。

- 输入：上游端口量（集水设施或上游处理单元）
- 输出：下游端口量（并联处理系列）
- 旧系统对应：mod `peishuijing`（交叉对照，非依据）
- golden 绑定：随各线 golden 覆盖
- 公式组（交付期冻结）：配水均匀性、堰/孔口出流水力
- 物理不变性（交付期进 tests/properties.py）：分配流量和=总流量（守恒）、各支路流量非负

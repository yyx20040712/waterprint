# conveyance_peishuiqu —— 配水渠（集配水线，M3）

渠道式配水，均衡多组构筑物进水。

- 输入：上游端口量（配水井或上游处理单元）
- 输出：下游端口量（并联处理系列）
- 旧系统对应：mod `peishuiqu`（交叉对照，非依据）
- golden 绑定：随各线 golden 覆盖
- 公式组（交付期冻结）：渠道断面、流速、堰口出流
- 物理不变性（交付期进 tests/properties.py）：流量守恒、流速≥最小防淤流速

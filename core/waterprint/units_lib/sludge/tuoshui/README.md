# sludge_tuoshui —— 污泥脱水（污泥线，M3）

机械脱水将污泥转变为可运输泥饼。

- 输入：上游端口量（xiaohua 污泥消化或 nongsuo 污泥浓缩）
- 输出：下游端口量（ganhua 污泥干化或外运）
- 旧系统对应：mod `wuni_tuoshui`（交叉对照，非依据）
- golden 绑定：污泥链全流程
- 公式组（交付期冻结）：脱水负荷、泥饼含水率、絮凝剂投配比
- 物理不变性（交付期进 tests/properties.py）：DS 守恒（泥饼+滤液）、泥饼含水率∈档位

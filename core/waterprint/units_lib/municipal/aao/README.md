# municipal_aao —— AAO 生物池（市政污水线，M2）

厌氧-缺氧-好氧工艺同步脱氮除磷与有机物去除。

- 输入：上游端口量（chuchenchi 初沉池或 tiaojiechi 调节池）
- 输出：下游端口量（erchunchi 辐流二沉池）
- 旧系统对应：mod `aao`（交叉对照，非依据）
- golden 绑定：municipal_34760
- 公式组（交付期冻结）：污泥龄/污泥负荷、分区容积（厌氧/缺氧/好氧）、需氧量、内回流与外回流比、剩余污泥量
- 物理不变性（交付期进 tests/properties.py）：分区容积和=总容积、需氧量≥0、回流比>0、剩余污泥≥0

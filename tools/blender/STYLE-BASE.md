## 一、材质板（ds 复审参数逐条在案）

| 材质 | metallic | roughness | basecolor | 用途 |
|---|---|---|---|---|
| 混凝土·池壁 | 0 | 0.82~0.86 | #B5B5AE~#BDBDB6（较 #a3a9ad 再降明度 12~18%） | 池体/池壁 |
| 混凝土·走道 | 0 | 0.84~0.88 | #C0BEB6 | 走道环/桥面格栅 |
| 混凝土·压顶 | 0 | 0.76~0.80 | #A8A8A2 | 边缘压顶 |
| 钢·不锈钢栏杆 | **1.0** | 0.28~0.35 | #C9CDD1 | 栏杆环/立柱 |
| 钢·灰蓝筒 | 0.90 | 0.40~0.45 | #6F7A82 | 中心筒（稳流筒） |
| 钢·结构桥 | 0.85~0.95 | 0.45~0.55 | #5E6971 | 刮泥桥桁架/驱动座 |
| 水（仅 PNG 面） | 0 | 0.12 | #2f7fd1 | preview_only 层 |

- 程序糙度：噪声 bump 幅度 0.01~0.02、尺度 2~5m（无贴图约束——
  glb 导出面剔除/烘焙待实测）；分缝：走道径向 3.5m/池壁水平 1.2m，
  缝内色 #8E8E88。
- FE 面（semanticColors·PoolBox 原语）与本表分立：模板走 glb 材质
  自持多档；语义色单源仅约束原语渲染（spec §10 材质=glb 单源）。

## 二、渲染档（Eevee 出图）

- 曝光 -0.5~-0.8EV+高光压缩 -0.3~-0.5；色管理 AgX/Filmic Medium
  High Contrast；目标主体直方图中位 48~58%、高光峰值 ≤0.92。
- 相机 50mm 等效/俯角约 36°/512² 透明底（P4 签核不变）。

## 三、细节档位表（辐流族——部件对照「中心传动刮泥机九件」）

| 档 | 部件 | 状态 |
|---|---|---|
| P0 已建 | 池壁厚杯体/走道环/双栏杆环/中心筒/桥（实心梁）/立柱原型 | v1 |
| P1 必补 | **周边出水堰槽+齿形堰板**/**桥桁架化（三角桁架+桥面格栅）** | 迭代二✓（2026-09-13 三段流过审） |
| P2 应补 | 撇渣管（半桥外缘）/驱动装置电机座/分缝 | 迭代二✓（同上） |
| P3 可选 | 浓缩栅条/电气检修盒/排渣斗 | 段二后按需 |

- **512 可辨性注记（三段流终裁落档）**：512² 定妆照 ≈10cm/px——
  0.1m 级构件（杆件/堰板/齿口）**不承诺 512 可辨**（物理极限非缺陷）；
  **材质分区（金属四档/混凝土三档）可辨性随尺度衰减为预期**——近景
  四档全辨、主视图降 2~3 档、512 定妆照降剪影级；细节可见性证据=近景
  正交图（评审件）+建模源几何事实；后续族复审不以此反复。
- 桁架杆径=0.10（调研 0.06→可辨性下限权衡——近景 2px 档）。
